# 국문 초록

[문서 안내](../README.md) · [최종 국문 논문](PAPER_KO.md) · [상세 결과·관측·가설](../RESEARCH_REPORT.md)

최종 논문과 같은 결과를 요약한 별도 초록이다. 공식 2페이지 조판본에는 초록을 추가하지 않았다. 논의·결론은 [최종 논문 4·5절](PAPER_KO.md#4-논의)을 기준으로 하고, 상세 관측·원인 가설·한계는 연구보고서에 모아 중복 서술을 줄였다.

본 연구는 ECQA와 Qwen3.5 계열에서 증류 경로와 KL 방향에 따른 확률 예측 품질을 비교하였다. 동결 4B SFT 교사에서 0.8B 학생으로 직접 증류하는 경로와, dev로 선정·동결한 2B 중간 교사를 사용하는 경로에 정방향 KL(FKL)과 역방향 KL(RKL)을 적용하였다. 네 최종 학생은 동일한 0.8B SFT의 독립 사본에서 시작했고 모든 KD 단계는 같은 사람 정답·설명 접두열, T=1의 순수 전체 어휘 KL, 3 epoch·1,419 updates를 사용하였다. 모델은 기존 dev ACC→Macro-F1→낮은 정답 NLL→이른 epoch 순으로 선정했으며 test 2,194문항을 선정에 사용하지 않았다. 완료 결과의 사후 해석에서는 첫 ANSWER의 A–E 조건부 NLL·Brier를 중심으로 보고 ACC·혼동 분석을 보조 근거로 제시한다. 직접 FKL은 SFT 대비 NLL·Brier가 각각 14.24%·8.43%, 중간 FKL은 16.76%·10.62% 낮았다. 중간 FKL의 NLL 0.867518·Brier 0.459455가 다섯 0.8B 조건 중 가장 낮았으며 ACC는 SFT와 같은 65.1322%였다. 직접 RKL은 ACC 65.6335%로 가장 높았지만 NLL·Brier는 SFT보다 나빴다. 중간 FKL과 SFT는 정답 1,429건으로 같지만 혼동행렬의 셀별 구성은 달랐다. 별도의 대응 문항 비교에서 중간−직접 정답 수 차이는 FKL −1건, RKL −9건이었다. 이에 따른 ACC 경로 차이는 각각 −0.0456%p·−0.4102%p, ΔR−ΔF는 −0.3646%p였다. 따라서 이번 고정 조건에서는 두 경로 모두 FKL이 SFT와 대응 RKL보다 낮은 NLL·Brier를 기록해 첫 답 A-E 조건부 확률 평가에서 우세했다. 경로 효과의 해석은 정확도와 확률 점수에 따라 달랐다. 단일 시드·모델 계열·자료에 한정되며, 통계적 유의성·내부 표현·확률 보정 개선이나 성능 차이의 인과 기제를 입증하지 않는다.
