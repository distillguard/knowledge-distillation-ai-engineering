# 논문 표기·약어 정리

[국문 원고](PAPER_KO.md)의 핵심 기호와 [연구 문서](../README.md)의 경로 별칭을 함께 정리했다. p(v)는 교사, q(v)는 학생의 전체 어휘 확률로 통일한다. A-E와 A–E는 같은 다섯 선택지, ΔR-ΔF와 ΔR−ΔF는 같은 차이의 차이를 뜻한다. 결과·조건을 바꾸거나 추가 실험을 수행하지 않았다.

## 경로와 실험 이름

| 표기 | 한국어 뜻·이번 실험에서의 의미 |
|---|---|
| D | 직접 경로(Direct). 동결 4B 교사에서 0.8B 학생으로 전달한다. |
| M | 중간 경로. 4B→2B→0.8B로 전달한다. 기존 MD의 M-FKL·M-RKL은 현재 논문의 중간 FKL·중간 RKL과 같다. |
| TA | 중간 교사(Teacher Assistant). 4B에서 배운 뒤 dev로 선정·동결한 2B 모델이다. 최종 0.8B 학생을 뜻하지 않는다. |
| F / R | 경로 비교 기호에서는 각각 FKL / RKL 방향을 가리킨다. |
| D-FKL / D-RKL | 직접 FKL / 직접 RKL. 결과 경로의 direct_fkl / direct_rkl과 대응한다. |
| M-FKL / M-RKL | 중간 FKL / 중간 RKL. 최종 학생 결과의 via_fkl / via_rkl과 대응한다. |
| KD | 지식증류(Knowledge Distillation). 교사 분포를 학생이 모사하는 학습이다. |
| SFT | 지도 미세조정(Supervised Fine-Tuning). 사람 정답·설명을 타깃으로 먼저 학습한 기준 모델이다. |
| 4B / 2B / 0.8B | 모델 규모 표기. B는 10억 단위 매개변수를 뜻한다. Brier의 첫 글자나 배치 크기를 뜻하는 기호와는 구별한다. |

## 확률분포와 학습 수식

| 표기 | 뜻·고정 조건 |
|---|---|
| p(v) | 응답 위치에서 어휘 항목 v에 대한 동결 교사의 확률. |
| q(v) | 같은 위치·어휘 항목의 학생 확률. RKL에서는 이 확률 가중치도 미분했다. |
| v / Σ | v는 어휘 항목, Σ는 모든 어휘 항목에 대한 합이다. 학습 KL은 전체 어휘 248,320개를 사용했다. |
| log | 자연로그. KL 수식과 NLL에서 사용한다. |
| KL | 쿨백-라이블러 발산(Kullback-Leibler divergence). 분포 사이의 비대칭 발산이다. |
| FKL | 정방향 KL. Σ p(v) log[p(v)/q(v)] = KL(p∥q). 교사 확률 p로 가중한다. |
| RKL | 역방향 KL. Σ q(v) log[q(v)/p(v)] = KL(q∥p). 학생 확률 q로 가중한다. |
| T | 분포를 계산할 때 사용하는 온도(temperature). 이번 KD에서는 T=1이다. |
| LoRA / r | 저랭크 적응 방식(Low-Rank Adaptation) / 저차원 행렬의 내부 차원(rank 설정값). r=8이다. |
| α / alpha | LoRA의 스케일 계수. α=32이며 표준 α/r 배율은 4다. 학습률 LR과 별도 설정이다. |
| LR | 학습률(Learning Rate). 모든 KD 단계에서 5×10^-6이다. |
| β1 / β2 / eps | AdamW의 1차·2차 모멘트 계수 / 수치 안정화 상수. .9 / .999 / 10^-8로 고정했다. |
| BF16 / FP32 | 각각 bfloat16 / 32비트 부동소수점. base는 BF16, 학습하는 LoRA와 KL 계산은 FP32다. |
| CE / EOS | 교차엔트로피(Cross-Entropy) / 응답 종료 토큰(End Of Sequence). 이번 KD에 CE를 혼합하지 않았고 EOS까지 응답 학습에 포함했다. |

## 평가 지표와 경로 차이

| 표기 | 정의·이번 결과 |
|---|---|
| ACC | 정확도(Accuracy). 첫 답이 gold와 일치한 비율. 표에는 비율×100으로 표시한다. |
| Macro-F1 | 거시평균 F1. A-E 각 선택지의 정밀도·재현율 조화평균 F1을 구한 뒤 다섯 값을 동일 가중 평균한다. 0~1에서 높을수록 좋다. |
| NLL | 음의 로그우도(Negative Log-Likelihood). 정답에 부여한 A-E 조건부 확률의 -log 값을 문항 평균한다. 낮을수록 좋다. |
| Brier | 브라이어 점수. A-E 확률벡터와 정답 원-핫 벡터의 제곱차 합을 문항 평균한다. 다섯 선택지 수로 추가 나누지 않으며 낮을수록 좋다. |
| Δ | 차이를 나타내는 델타(delta). 여기서는 아래에 정의한 ACC 차이다. |
| ΔF | ACC(중간 FKL) - ACC(직접 FKL) = -0.045579%p. 이번 test에서 중간 경로의 정답이 1건 적다. |
| ΔR | ACC(중간 RKL) - ACC(직접 RKL) = -0.410210%p. 이번 test에서 중간 경로의 정답이 9건 적다. |
| ΔR-ΔF | RKL의 경로 차이에서 FKL의 경로 차이를 뺀 값. -0.364631%p이며, 방향별 경로 차이를 요약한 관측값이다. |
| %p | 백분율 포인트(percentage point). ACC 65.6335%와 65.1322%의 차이는 약 0.5014%p다. 상대 증가율(%)과 구분한다. |
| n / A-E | n은 문항 수(각 조건 test n=2,194). A-E는 다섯 답 선택지의 이름이다. |

## 자료·실행 표기

| 표기 | 뜻·현재 사용 |
|---|---|
| ECQA | 사람 설명을 포함한 CommonsenseQA 자료의 이름. 실험 자료는 영문이며 논문 서술을 국문으로 작성했다. |
| train / dev / test | 학습 / 검증·모델 선정 / 최종 시험 자료. 각각 7,566 / 1,079 / 2,194문항이다. |
| epoch / update | 전체 학습 자료를 한 번 사용하는 단위 / optimizer를 한 번 갱신하는 단위. 각 KD 단계는 3 epoch·1,419 updates다. |
| seed | 난수 초기값. 이번 비교는 seed 10 한 번이다. |
| ANSWER / EXPLANATION / gold | 응답의 답·설명 구분 표식 / 자료에 기록된 정답. 평가에서는 헤더·구분자 형식을 강제하고 A-E의 답을 모델이 선택한다. |
| h / FLOPs | 시간 단위(hour) / 부동소수점 연산 수. 상세 보고서의 h는 실행 기록 시간의 합으로 FLOPs를 측정한 값이 아니다. |

## 혼동하기 쉬운 구분

- ΔF·ΔR의 기준은 각각 같은 KL의 직접 경로다. SFT 대비 ACC 차이는 별도로 쓴다.
- F1의 F는 평가 지표의 이름이며, ΔF의 FKL 방향 기호와 구별한다. 대문자 R은 RKL 방향, 소문자 r은 LoRA 랭크다.
- p(v)의 p는 교사 확률이다. %p의 p는 백분율 포인트라는 단위의 일부다.
- NLL·Brier는 이 실험에서 첫 ANSWER의 A-E 조건부 확률 점수다. 전체 어휘 KL·설명 사실성·확률 보정 오차만의 지표와 구분한다.
- 음의 ΔF·ΔR은 이번 test에서 중간 경로의 ACC가 직접 경로보다 낮았다는 뜻이다. ΔR-ΔF의 유의성이나 인과적 기제를 검증한 것은 아니다.
