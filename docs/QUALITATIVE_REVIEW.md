# Dolly 생성의 근거 일치와 오류 사례

2026-10-19 기준 GPT-2 XL/base와 OPT-2.7B/125M의 선택된 SFT 응답을 검토했다. 정량 평가와 동일한 Dolly 500문항·seed 10의 저장된 응답이며 새로 생성하지 않았다. 아래 판정은 제공된 context와 질문에 대한 사례별 검토다. 외부 사실 검증, 독립적인 사람 평가, 전체 정답률을 뜻하지 않는다.

## 사례 선정

500문항 중 context가 있는 `closed_qa`·`information_extraction` 63문항을 대상으로, 교사와 학생의 **정규화 exact match** 조합으로 층을 나눴다. 소문자 변환·ASCII 구두점 제거·공백 정리를 사용하는 기존 EM이며, 관사는 제거하지 않는다. EM=0을 오답으로 간주하지 않는다. 각 비어 있지 않은 층에서 context가 가장 짧은 문항을 고르고 동률은 ID로 정렬했다. 사후 탐색이며 무작위 표본이 아니다.

| 조합 | 교사 EM=100·학생 EM=100 | 교사만 EM=100 | 학생만 EM=100 | 둘 다 EM<100 |
|---|---:|---:|---:|---:|
| GPT-2 XL → base | 0 | 1 | 0 | 62 |
| OPT-2.7B → 125M | 0 | 1 | 0 | 62 |

층별 문항 수는 사례 선정 과정을 설명할 뿐, 교사 우위의 검정이나 semantic accuracy가 아니다. 특히 두 응답이 모두 EM<100인 층에는 올바른 바꿔쓰기가 포함될 수 있다. 공개 문서에는 문항 ID와 오류 유형만 적고 원문·생성 응답은 Git에서 제외한 `tmp/`에 보관한다.

## 원문 근거에 대한 관찰

| 조합·문항 ID | 교사 관찰 | 학생 관찰 | 해석 범위 |
|---|---|---|---|
| GPT-2·`valid:21` | context에 명시된 평균 수명 범위를 유지 | context와 다른 수명 범위를 생성 | 교사의 답변이 해당 질문의 근거를 보존한 사례 |
| GPT-2·`valid:91` | 직업은 유지하지만 context와 다른 생몰일을 생성하고 다른 인물 같은 내용을 이어붙임 | 이름의 일부만 출력하고 직업 설명을 제공하지 않음 | 교사에도 근거 모순이 있으며 학생에는 불완전 응답이 있음 |
| OPT·`valid:276` | 두 번째 앨범 하나를 추출하는 지시를 충족 | 목표 앨범을 포함하지만 다른 항목과 중복 항목을 함께 나열 | 정답 문자열을 포함하는 것과 추출 지시를 지키는 것은 다름 |
| OPT·`valid:91` | 직업은 유지하지만 context가 제공하지 않은 출생지를 추가 | 직업·일부 날짜와 함께 context에 없는 수상·활동 등의 내용을 대량 추가 | context로 뒷받침할 수 없는 확장. 추가 내용이 모두 외부 사실상 거짓이라고 판정한 것은 아님 |

`valid:91`은 입력 context보다 참조 답변이 더 긴 문항이다. 위 주석은 입력에 실제로 제시된 이름·생몰일·직업을 기준으로 했으며, 긴 참조 답변 전체가 입력 context에서 추출 가능하다고 가정하지 않았다.

## 같은 사례의 SFT 전후

위에서 이미 선정한 `valid:21`·`valid:276`의 원본 checkpoint 응답도 동일 seed·prompt·정밀도의 저장 결과로 대조했다. 새로운 표본을 골라 개선률을 산출한 것은 아니다.

| 모델·문항 ID | 원본 관찰 | SFT 후 관찰 |
|---|---|---|
| GPT-2 base·`valid:21` | 수명을 직접 답하지 않고 관련 없는 장문 설명으로 확장 | 짧은 수명 답변 형식은 갖췄지만 context의 숫자와 모순 |
| GPT-2 XL·`valid:21` | 질문에서 벗어나 다른 입력 형식과 설명을 이어붙임 | context에 명시된 수명을 간결하게 답변 |
| OPT-125M·`valid:276` | 요청한 두 번째 앨범을 추출하지 않고 다른 음악·인물 내용을 나열 | 목표 항목을 포함하지만 과잉 추출·반복이 남음 |
| OPT-2.7B·`valid:276` | 다른 질문과 연구 제안서 같은 내용으로 이탈 | 요구한 단일 항목 추출을 충족 |

이 사례에서는 **응답 형식·지시 따르기의 보완과 사실·근거의 정확성을 분리**해야 한다. 학생의 답변 형식이 개선돼도 숫자 오류나 과잉 추출이 남을 수 있다. 평균 점수 상승을 모든 답변의 사실성 개선으로 바꾸어 해석하지 않는다.

## 연구 설계에 대한 시사점

1. 교사·학생의 평균 ROUGE-L·METEOR·BERTScore 차이는 응답 차이를 설명하는 자료이며, 이 격차만으로 조합을 제외하지 않는다. 교사의 절대 수행과 실제 응답 품질도 확인해야 하며 교사의 모든 토큰이 더 정확하다는 보장은 없다. `valid:21`과 `valid:276` 같은 유용한 신호와 `valid:91` 같은 교사 오류를 함께 보존해 분석해야 한다.
2. forward-KL·reverse-KL·Hard/Soft gate의 비교에서는 같은 입력과 prefix에서 손실·gate·confidence를 기록해야 한다. 이 사례들만으로 특정 KL이나 gate가 오류를 해결한다고 결론내리지 않는다.
3. 단일 pass entropy나 MC 불확실성은 문맥 근거에 대한 정답 판정과 다르다. confidence로 손실을 바꾸는 것과 학습을 거르는 것의 효과는 동일한 조건의 본 실험에서 별도로 확인해야 한다.
4. 어휘 다양성은 사실성 검증을 대신하지 않는다. 근거 없는 긴 확장은 Distinct-4가 높더라도 좋은 답변으로 볼 수 없다. 원문 기반 오류, 불완전 응답, 과잉 추출을 정량 지표와 함께 살핀다.

현재 사례 검토는 후보 선정의 보조 근거다. 오류 빈도·사람 선호 승률·통계적 유의성은 산출하지 않았으며, 본 실험의 독립 평가셋이나 사전 등록된 분석으로 표시하지 않는다.
