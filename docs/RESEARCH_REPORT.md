## 1. 초록

본 연구는 생성형 언어모델의 지식증류에서 **어떤 손실로 배울지 결정하는 것**과 **학습 갱신을 받아들일지 결정하는 것**의 역할을 비교·시각화하는 것을 목적으로 한다. Hinton의 soft target·온도 개념, MiniLLM의 KL 방향과 생성 학습 관점, CaRE-KD의 confidence gate와 Revival을 이론적 근거로 삼는다. 선정한 교사·학생과 Dolly 공통 학습 조건에서 고정 FKL/RKL, Hard/Soft gate, 같은 손실의 Revival 유무와 결합을 대조하도록 설계한다. 확률분포·gate·불확실성·갱신 수용/거절·생성 응답을 연결해 해석한다. **이 초안에는 KD 방법 비교나 개선 효과에 대한 결론이 없다.**

## 2. 연구 배경과 목적

생성형 LLM의 학생은 교사가 가진 복잡한 응답 분포를 제한된 용량으로 학습한다. 어떤 확률 정보를 전달하고 어떤 생성 context에서 학습하느냐에 따라 학습 신호가 달라질 수 있다. 또한 교사의 confidence와 불확실성은 실제 정답 여부와 같은 개념이 아니므로, 지도 신호를 따르는 방식을 분석할 필요가 있다. [Hinton §2](https://arxiv.org/pdf/1503.02531v1), [MiniLLM §1–2](https://arxiv.org/html/2306.08543v4), [CaRE §2](https://arxiv.org/html/2609.36734v1).

본 연구는 문헌에서 제시한 개입을 분리해 읽고, 실제 모델에서 어떤 차이가 관측되는지 설명하는 비교·분석 연구다. 주요 산출물은 원리 설명, 출처가 있는 수식·자료, 방법별 시각화, 응답·평가 결과와 한계다. 계산 시간과 메모리는 현재 컴퓨터에서 연구를 끝낼 수 있는지 판단하는 제약으로 기록한다.

## 3. 이론적 배경

### 3.1. 생성형 LLM과 지식증류의 위치

생성형 LLM은 입력과 앞서 생성한 토큰에 조건부로 다음 토큰의 확률을 계산한다. 교사 분포 P와 학생 분포 Q를 비교할 때는 같은 입력·prefix·어휘 좌표인지 확인해야 한다.

지식 유형의 일반적인 분류는 응답/출력 기반·특징 기반·관계 기반이다. 확률분포를 이용한 이번 비교는 응답/출력 기반에 속한다. 세 유형 전체를 실험 대상으로 삼는 것은 아니다. [Gou 외, KD Survey §2](https://arxiv.org/pdf/2006.05525v7).

### 3.2. Soft target·온도·CE/KL

실제 정답 토큰을 지도하는 것과 교사의 확률분포를 전달하는 것은 다른 학습 신호다. 온도 T는 logits를 나누어 분포를 바꾸며 그라디언트 크기에도 영향을 준다. Hinton의 온도·보정 설명은 적용 가정과 함께 읽는다. 원문이 특정 값을 사용했다는 사실을 현재 조건의 최적성으로 해석하지 않는다. [Hinton §2–2.1](https://arxiv.org/pdf/1503.02531v1).

같은 context에서 다음과 같이 정의한다.

$$
D_F=KL(P\|Q),\qquad D_R=KL(Q\|P).
$$

FKL/RKL의 차이는 손실 방향의 차이다. 생성 학습에서는 학습 응답과 prefix의 출처도 확인해야 한다. 단순한 토큰 RKL 구현과 policy gradient·sampling·안정화 등을 포함하는 MiniLLM 전체 알고리즘을 구분한다. [MiniLLM §2](https://arxiv.org/html/2306.08543v4).

## 5. 연구 질문과 비교 방법

### 5.1. 연구 질문

- **RQ1:** 같은 조건에서 FKL과 RKL은 학습 신호·분포·응답을 어떻게 다르게 변화시키는가?
- **RQ2:** Hard/Soft gate의 선택·혼합과 미분 차이는 어떤 동작·결과로 나타나는가?
- **RQ3:** 같은 손실에서 Revival을 적용하면 어떤 갱신이 수용·거절되고 결과는 어떻게 달라지는가?
- **RQ4:** 손실 적응과 갱신 거절을 결합하면 각 장치만 사용한 경우와 무엇이 달라지는가?

### 5.2. 손실 적응: FKL/RKL과 Hard/Soft gate

공통 표현을 다음과 같이 둔다.

$$
L_g=gD_F+(1-g)D_R.
$$

| 조건 | 정의·역할 | 비교할 내용 |
|---|---|---|
| FKL | g=1로 고정 | 해당 context에서 교사 분포를 맞추는 신호 |
| RKL | g=0으로 고정 | 방향 변경에 따른 신호·분포 변화 |
| Hard gate | confidence 차이로 두 분기 중 하나를 선택 | 토큰별 선택과 경계 부근의 동작 |
| Soft gate | confidence 차이로 혼합 비중을 연속적으로 결정 | 혼합 비중과 gate를 통한 미분의 영향 |

CaRE의 기준 정의는 c(P)=1−H(P)/log|V|, Δc=c(P)−c(Q), g_hard=1[Δc≥0], g_soft=σ(Δc−m)이다. Hard/Soft는 **gate**의 구분이며 hard label/soft target과 다르다. 원문에서는 margin·연속 혼합·gate의 미분 여부가 함께 달라지므로 결과를 연속성 하나의 효과라고 단정하지 않는다. [CaRE §2.1·3.1](https://arxiv.org/html/2609.36734v1).

m·추가 scale·온도는 현재 실험 값으로 확정하지 않았다. 기존 분석에서 확인한 식 (3)과 Figure 2의 scale 차이는 공식 실행 config와 대조할 항목이다.

### 5.3. 선택적 갱신: Revival

Revival은 MC dropout으로 추정한 교사·학생 BALD와 각각의 과거 분포 quantile을 이용한다. 단일 분포의 entropy confidence를 그대로 같은 추정량으로 사용하지 않는다. **손실을 선택하는 gate와 갱신을 수용·거절하는 Revival은 신호와 개입 위치가 다르다.** [CaRE §2.2](https://arxiv.org/html/2609.36734v1).

이번 비교에서는 원문의 추정·mask 집계 단위와 실제 optimizer 동작을 확인한다. loss·gradient를 0으로 만드는 것과 optimizer step 생략은 구분한다. MC dropout이 비퇴화 신호를 만드는지와 그 신호의 유익성도 별개로 읽는다. 거절 여부 자체를 실제 오답의 판정으로 사용하지 않는다.

### 5.4. 교사 응답 학습·증강 — 추가 후보

SeqKD는 교사가 생성한 문장을 학습 대상으로 사용하는 방식이다. 같은 선정 데이터의 학습 입력에 교사 응답을 생성하거나 여러 응답을 선별해 추가하는 구성을 관련 방법으로 설명한다. 실제 실험 포함 여부는 아직 미정이다. [SeqKD 원문](https://aclanthology.org/D16-1139/), [MiniLLM baseline](https://arxiv.org/html/2306.08543v4).

추가한다면 교사 응답·원본 응답의 역할, 생성·선별 기준, 같은 원본에서 파생한 group과 학습량을 기록한다. 응답 증강 효과와 단순 학습량 증가의 효과를 구분한다.

## 6. Dolly 기반 모델 선정

### 6.1. 자료의 역할

학습은 Dolly로 고정했다. 공통 분할은 학습 11,117건·개발 검증 975건·Dolly 선정 평가 500건이다. 같은 원본 ID·전체 응답·mask를 사용하고 모델별 tokenizer 차이는 기록한다. UltraChat·MetaMathQA의 감사 기록은 [후속 데이터 비교 설계](DATASET_SFT_COMPARISON.md)에 보관하며 현재 학습에 포함하지 않는다.

예비 생성 평가는 활성 8모델의 **Dolly 500문항**이다. 후보 축소 후 Self-Instruct 242·S-NI 1,694·Vicuna 80을 추가한 모델은 총 2,516문항이다. 추가 세 자료는 학습이 아닌 일반화 평가다. SST-2 872·BoolQ 3,269문항은 편향·확률 품질의 보조 진단이다. 자료 revision·다중 정답·전처리·실행 조건은 [생성 평가 명세](GENERATION_EVALUATION.md)에 고정한다.

### 6.2. 교사·학생 후보

| 계열 | 교사 후보 | 학생 후보 |
|---|---|---|
| GPT-2 | XL | base |
| OPT | 2.7B | 125M |
| OpenLLaMA | 7B | 3B |
| Gemma-2 | 9B-IT | 2B-IT |

모두 고정한 공개 revision에서 독립적으로 LoRA SFT한다. GPT-2 두 모델은 BF16이며 추가 모델은 기존 메모리 점검 정책을 따른다. 모델 ID·학습 이력·정밀도·template와 근거는 [SFT 비교 계획](DOLLY_SFT_MODEL_SELECTION.md)을 따른다. pretrained와 post-training 모델이 섞여 있으므로 구조·크기·양자화 중 한 요소만의 효과로 해석하지 않는다.

### 6.3. 체크포인트와 조합의 선택

검증 NLL은 같은 모델 내부의 두 LR·epoch checkpoint를 고르는 기준이다. 서로 다른 tokenizer의 NLL로 모델 순위를 정하지 않는다. 예비 체크포인트 선택 후 원본/SFT Dolly 평가와 보완 채점으로 후보를 좁히고 외부 평가·보조 진단·오류 분석·증류 실행 점검을 거쳐 한 교사·학생 조합을 선정한다. 이번 선정 전에 추가 SFT 탐색은 시작하지 않는다. 원문 기반 SFT 탐색·학생 초기화는 선정한 한 조합의 본 실험 설계로 남긴다. 세부 단계와 완료 근거는 [계획서 §6](RESEARCH_PLAN.md)과 [생성 평가 계획](GENERATION_EVALUATION.md)을 따른다.

최고 ROUGE-L 하나나 임의의 최소 격차로 조합을 자동 선정하지 않는다. 과제별 우위의 일관성·응답 오류·분포 비교 가능성·실행 가능성을 근거로 선정 이유와 한계를 남긴다. 현재 최종 조합은 미정이다.

## 7. 실험 설계와 실행 환경

### 7.1. 구성요소 대조

| 대조 구조 | 손실 | Revival | 확인할 역할 |
|---|---|---|---|
| 고정 기준선 | FKL 또는 RKL | 없음 | KL 방향의 차이 |
| 손실 적응만 | Hard 또는 Soft | 없음 | 손실 선택·혼합의 역할 |
| 갱신 거절만 | 대응 기준선과 같은 손실 | 있음 | 같은 손실에서 갱신 수용·거절의 역할 |
| 결합 | 대응 조건과 같은 gate | 있음 | 같은 gate에 Revival을 추가한 변화 |

모든 조합의 실행을 확정한 것은 아니다. 원문 설정·구현·자원 확인 후 실제 목록을 동결한다. [CaRE Table 2](https://arxiv.org/html/2609.36734v1#S4.T2)는 같은 손실의 Revival 유무를 대조하는 근거이며 위 표 전체가 원문과 동일한 실험이라고 표시하지 않는다.

### 7.2. 공통 조건과 구현 확인

- 교사·학생 초기 상태, 데이터·분할, tokenizer·prompt·mask, 평가와 학습량 정의를 기록한다.
- reference/teacher/student 중 학습 prefix를 어디에서 얻는지 정하고 조건별로 같은 규칙을 사용한다. SGO와 teacher forcing은 아직 채택 전이다.
- 같은 입력의 고정 진단과 실제 자유 생성·학생 rollout의 변화를 구분한다.
- 같은 손실에서 Revival 유무를 비교하고 처리 입력 수와 실제 갱신 수를 함께 남긴다.
- 서로 다른 목적함수의 training loss 숫자만으로 방법의 성능을 순위화하지 않는다.

### 7.3. 실행 환경과 증류 점검

현재 장비는 RTX 5060 Ti 전용 VRAM 16,311 MiB·RAM 31.62 GiB·Ryzen 5 7500F다. Python 3.12.14·PyTorch 2.11.0+cu128와 현재 학습 환경의 상세 버전은 [공통 실행 지침](EXPERIMENT_GUIDE.md)을 따른다. GPT-2 XL/base의 최초 동시 적재·짧은 추론은 [과거 실행 기록](../results/model_preflight.json)에 보관한다.

단독 모델의 SFT와 교사·학생을 함께 사용하는 KD는 메모리·연산 경로가 다르다. 조합 선정 전에 같은 어휘 좌표·prefix에서 학생 backward·optimizer update와 필요한 생성·MC 경로를 점검하고 peak memory·시간을 기록한다. 현재 모든 후보의 전체 KD 경로를 통과한 상태는 아니다.

### 7.4. 과거 공개 SFT 기준선

저자가 공개한 Dolly-SFT XL/base의 평가는 [공개 SFT 기준선](SFT_BASELINE_EVALUATION.md)에 별도로 기록했다. 그 점수·5개 생성 seed 결과를 이번 직접 SFT의 점수나 미학습 원본으로 취급하지 않는다. 원본 대비 SFT의 생성 향상 폭을 주장하려면 별도의 동일 조건 원본 평가가 필요하며 아직 수행하지 않았다.

### 7.5. 직접 SFT와 생성 평가의 초기 관측

GPT-2 base·XL은 두 LR 후보를 각각 3epoch 학습했고 LR 2e-4가 선택됐다. 선택 checkpoint는 base epoch 3, XL epoch 2다. Dolly 500문항·생성 seed 10의 ROUGE-L은 base 14.68, XL 20.13으로 차이는 +5.45다. 두 모델의 분류 진단에서는 XL의 BoolQ accuracy 62.43%가 다수 클래스 기준선 62.16%와 가깝고 macro-F1은 42.49%여서 accuracy만으로 교사 성능을 판단하지 않는다.

2026-10-16에 두 모델의 네 생성 benchmark 평가를 모두 완료했다. XL/base의 ROUGE-L은 Dolly 20.13/14.68, Self-Instruct 12.89/7.60, S-NI 20.95/12.00, Vicuna 14.28/11.56이다. 네 과제에 같은 가중치를 준 평균은 17.06/11.46으로 XL이 +5.60 높다. 이는 해당 공통 문항·생성 seed에서 reference 겹침의 차이이며 사람의 선호·사실성 판정이나 증류 효과의 증거는 아니다. 최종 조합은 아직 선정하지 않았다.

같은 날 OPT-125M도 BF16에서 두 LR 후보를 각각 3epoch 학습했다. LR 1e-4의 최저 개발 NLL은 2.2121, LR 2e-4는 2.1956으로 후자의 epoch 3 checkpoint를 선택했다. 선택 후보의 실제 epoch별 NLL은 2.2239 → 2.2029 → 2.1956이며 SFT 전 같은 모델의 개발 NLL은 2.8295였다. 원본 ID·마스크·소스/자료 hash·실제 갱신/저장/재적재·전용 VRAM 점검을 확인했다. 이 값은 같은 모델의 응답 예측 손실이며 다른 계열과의 성능 순위가 아니다. 선택 adapter의 Dolly 500문항 생성 점수는 별도로 보고한다.

선택한 OPT-125M의 Dolly 500문항·seed 10 평가도 완료했다. ROUGE-1/2/L은 22.64/7.95/17.08, 정규화 exact match는 1.40%, 평균 새 토큰 수는 64.43, 생성 상한 도달률은 4.00%, 빈 응답률은 0%다. Exact match를 자유 생성 과제 전체의 의미상 정답률로 해석하지 않는다. 같은 500개 ID·adapter/평가 fingerprint·CSV hash·문항별 지표 평균을 검증했다. 외부 3종은 후보 축소 후 평가한다.

2026-10-17에는 OPT-2.7B의 BF16 예비 SFT를 완료했다. 두 LR 모두 epoch 2가 최저였으며 LR 1e-4의 개발 NLL 1.6362가 LR 2e-4의 1.6374보다 낮아 전자를 선택했다. 두 후보의 차이 약 0.0013은 사전 명세된 선택 기준에 따른 값이며 학습률의 통계적 우월성을 뜻하지 않는다. 실제 epoch별 NLL은 LR 1e-4에서 1.6463 → 1.6362 → 1.6475, LR 2e-4에서 1.6383 → 1.6374 → 1.6623이다. 같은 모델의 SFT 전 NLL은 2.0660이었다. epoch 3 종료값과 epoch 2의 최적 checkpoint 복원 후 재평가값을 구분했다.

ROUGE-1/2/L은 29.35/11.64/21.52, 정규화 exact match는 2.40%, 평균 새 토큰 수는 78.59, 생성 상한 도달률은 5.20%, 빈 응답률은 0%다. 동일 문항의 OPT-125M 대비 평균 ROUGE-L 차이는 +4.44이며 교사 우위/동률/학생 우위 문항은 302/38/160이다. 이는 reference 겹침의 문항별 비교이며 사람의 선호 승률이나 증류 효과가 아니다. 선택 adapter·자료·평가 fingerprint와 CSV hash, 500개 ID, 원본 응답의 재채점 및 문항별 평균을 확인했다. 기존 응답에 문항별 EOS 정보가 없어 상한 도달 여부는 문항별로 추정하지 않고 기존 평가의 집계값만 보존했다. 이로써 선정 대상 8개 중 4개의 SFT·Dolly 예비 평가가 완료됐으며 다음 모델의 학습을 이어간다.

**제외 모델의 보존 기록:** 2026-10-16에 Qwen3.5-0.8B의 두 LR 후보도 각각 3epoch 학습을 완료했다. BF16·LR 2e-4의 epoch 1 체크포인트가 개발 NLL 1.7261로 선택됐다. LR 1e-4의 최저 NLL은 1.7277이며 두 후보의 차이는 약 0.0015다. 동일 모델의 SFT 전 개발 NLL은 2.3867이었다. LR 2e-4의 실제 epoch별 NLL은 1.7261 → 1.7628 → 1.8839로, epoch 3 종료값과 최저 체크포인트 복원 후 재평가값을 구분한다. 이 비교는 검증 기준 응답의 예측 손실이며 생성 정답률이나 다른 계열 대비 순위가 아니다. 이후 범위 축소로 Qwen은 선정 대상에서 제외했다. Dolly 500문항 생성 완료 결과와 SFT checkpoint는 보존하고 외부 평가 중 실행을 중지했다.

현재 관측은 단일 생성 seed이며 seed 간 변동이나 통계적 유의성을 추정하지 않는다. GPT-2 XL은 두 LR 모두 epoch 2의 개발 NLL이 가장 낮고 epoch 3에 상승했으므로 epoch 증가가 생성 점수 개선을 보장한다고 해석하지 않는다. 이 3epoch LoRA 비교는 MiniLLM의 전체 10/20epoch SFT baseline 재현이 아니다.

모델별 최신 완료 범위·선택 NLL은 [SFT 진행 기록](SFT_PROGRESS.md), 네 benchmark의 검증된 점수와 동일 문항 차이는 [생성 주 평가](../results/generation_benchmarks_v1/REPORT.md), SST-2·BoolQ는 [보조 진단](../results/dolly_sft_v1/REPORT.md)을 따른다. 미완료 모델·과제의 점수를 보간하지 않는다.

## 9. 평가와 시각화 설계

### 9.1. 평가의 역할과 비교표

생성 평가는 정답을 보여주지 않고 직접 생성한 응답을 확인한다. ROUGE-1/2/L은 reference 겹침, exact match는 정규화 문자열 일치이며 사실성·지시 준수를 직접 판정하지 않는다. 2026-10-18에 METEOR·BERTScore·Distinct-4 추가 실행을 승인했으며 아직 실제 채점하지 않았다. 저장 응답을 재사용하므로 추가 epoch나 기존 답변 재생성은 필요 없다. 원본 checkpoint의 동일 조건 생성 기준선은 별도 추론으로 추가한다. 구체적 절차와 지표 설정 근거는 [생성 평가 계획](GENERATION_EVALUATION.md)을 따른다. 외부 judge·사람 평가는 실행하지 않았다.

보고할 비교표는 **모델×benchmark×지표**이며, 계열 내 같은 문항의 교사−학생 차이와 오류를 함께 제시한다. 서로 다른 지표를 임의 가중합하지 않는다. 최종 조합의 선정 근거는 과제별 일관성·응답 검토·실행 가능성과 연결한다.

SST-2·BoolQ의 accuracy·macro-F1·클래스별 오류·Brier는 보조 진단이며 후보 원본/SFT의 후속 평가에 ECE도 추가한다. 현재 Brier를 MiniLLM ECE의 재현으로 표시하지 않는다. entropy·KL·gate·BALD·수용률은 본 KD 동작 진단으로, 생성 수행의 대체 지표가 아니다.

본 KD의 개선은 **같은 학생의 SFT 기준선 대비** 측정한다. 현재 SFT 후 모델 간 격차와 원본 대비 SFT 향상, 이후 KD 향상을 구분한다. 이미 조합 선정에 사용한 평가 자료를 독립적인 최종 test로 취급하지 않는다.

### 9.2. 선정 평가와 본 증류의 표시 원칙

현재는 8개 모델의 생성 점수와 계열 내 격차를 공통 축으로 표시한다. 본 증류에서는 선정한 한 조합의 SFT 분포 → 학습 신호·gate → Revival → 응답 변화를 연결한다. 전체 진행 순서는 [계획서 §5.2.3](RESEARCH_PLAN.md)을 따른다.

교사·학생 색상, 대응 패널의 축과 토큰 순서를 고정한다. 주요 토큰의 합집합을 표시하고 빠진 확률은 `기타 어휘`로 남기며, KL·entropy는 전체 어휘에서 계산한다. 표시할 토큰 수는 가독성을 위한 설정으로 기록하고 분포를 다시 정규화하지 않는다. 확률 차이는 0을 중심으로, heatmap은 공통 범례·범위·mask로 읽는다.

분포 비교·gate 곡선·Revival 흐름은 각각 한 질문을 설명하는 그림으로 나눈다. 모든 그림에 실제 입력·prefix 위치·checkpoint 단계·revision·정밀도·온도 변환·계산 범위를 남긴다. 원문 인용·수식 예시·기반 모델 추론 점검·선정 데이터의 SFT 후 실측을 구분하며 아직 실행하지 않은 단계의 값을 채우지 않는다.

### 9.3. 예정 자료

| 자료 ID | 그림·표 | 기록할 내용·해석 조건 |
|---|---|---|
| V1 | 전체 학습 흐름도 | 입력·분포·손실·gate·Revival·실제 갱신의 연결 |
| V2 | 같은 context의 FKL/RKL 분포 비교 | 토큰 확률·차이·학습 신호. 표시 토큰 외의 확률질량 보존 |
| V3 | Hard/Soft gate 곡선 | confidence 차이·실제 margin/scale·미분 조건 |
| V4 | 토큰별 heatmap | confidence·gate·KL·학습 신호와 유효 mask |
| V5 | 불확실성과 수용/거절 흐름 | teacher/student BALD·quantile·mask·실제 갱신 |
| V6 | 수용/거절된 자료의 분포 | category·길이·불확실성, 전체 처리 자료와의 비교 |
| V7 | 공통 validation·최종 평가 | 학습량·표본 수·변동과 처리 입력/실제 갱신 수 |
| V8 | 같은 질문의 생성 응답 표 | reference·교사·방식별 학생 응답, 길이·반복·과제 수행 |

이는 본 KD의 예정 자료 목록이며 해당 KD 그림은 아직 생성하지 않았다. SFT 선정 평가의 표·그림은 위 실행 보고서에 별도로 있다. 좋은 예제만 선택하지 않고 선정 이유·실패·무변화를 함께 남긴다. 문헌 그림·수식 예시·실측을 구분하고 축·조건·반복·오차 정의를 표시한다.

## 10. 실험 결과 — 실행 후 작성

**현재 KD 학습·평가는 미실행이다. Dolly 직접 SFT의 초기 결과는 §7.5에 기록하며, 아래 KD 방법 비교의 개선·악화·동등성에 관한 결론은 없다.**

실행 후에는 실제 수행한 조건과 누락·실패 이유를 적고, FKL/RKL, Hard/Soft, 같은 손실의 Revival 유무, 결합 결과를 대응 표·그림으로 작성한다. 예상 방향에 맞지 않는 결과와 무변화도 기록한다. SeqKD·응답 증강은 실제 수행한 경우에만 추가 결과로 보고한다. 임의 예시 수치를 측정값처럼 채우지 않는다.

## 11. 논의와 해석의 한계

- confidence·BALD와 실제 정오·지도의 유익성을 구분한다. Revival의 거절 자체가 오류 판정은 아니다.
- Hard/Soft의 margin·혼합·미분 차이를 함께 읽고 연속성 하나의 원인 효과라고 단정하지 않는다.
- 갱신 거절에서 달라지는 입력 노출·실제 갱신 수와 optimizer 동작을 설명한다.
- 학습 loss 감소와 과제 수행 개선을 구분한다. 차이가 검출되지 않았다고 동등성을 선언하지 않는다.
- 실제 모델·분할·길이·평가·원문과의 변경 범위 안에서 결과를 해석한다.
- 작은 GPT-2 조합의 관측을 최신 LLM 전체의 일반적 효과로 확대하지 않는다. 기반 모델과 Dolly 준비 checkpoint를 구분한다.
- 원문의 조건부 이론·보고값과 우리 관측을 구분한다. 개별 구성요소와 전체 CaRE-KD의 결과를 섞지 않는다.

## 12. 결론과 후속 연구 — 결과에 따라 작성

현재는 Dolly 공통 학습·개발 분할에서 8개 모델의 예비 SFT와 Dolly 500문항 생성 평가를 진행한다. 외부 3종·새 보조 진단은 후보 축소 후 진행한다. 최신 완료 범위는 상단 진행 기록을 따른다. 보완 평가·오류 분석·실행 점검 후 조합을 선정하고, 본 KD에서 KL 방향·손실 적응·갱신 거절·결합의 차이를 관측한다. 아직 특정 KD 방법의 우수성이나 새로운 효과에 관한 결론은 없다.

한국어 적용, 다른 모델·과제, 교사 응답 증강 등은 관측 결과와 자원에 근거해 후속 후보로 검토한다. 결론을 먼저 정해 실험 결과를 맞추지 않는다.
