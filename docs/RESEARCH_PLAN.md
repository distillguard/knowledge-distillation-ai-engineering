계획 갱신일: 2026-10-19, Asia/Seoul.

**산출물 수준 갱신 (2026-10-19):** 사용자는 재현·분석을 토대로 학술대회에 제출하는 논문을 목표로 한다. 단순 재실행과 시각화에 머물지 않고 기존 연구와 구분되는 질문·통제 비교·관측 근거를 마련한다. 신규 알고리즘 개발 여부는 연구 질문에 따라 정하며, 선행연구 검토와 실제 결과 없이 독창성이나 성능 개선을 주장하지 않는다. GPT-2 XL/base 주축은 구성안이며 최종 조합과 기여는 미확정이다. 단순 Reverse-KL 손실과 MiniLLM 전체 알고리즘을 구분하고, CaRE의 기존 Hard/Soft gate ablation을 새로운 제안으로 표시하지 않는다. 기존 8모델 예비 결과는 보존하며, 새 본 실험의 초기화·학습·평가 명세는 별도 확정한다.

**제출 목표와 근거:** [기존 lightjudge 연구계획서](https://github.com/distillguard/lightjudge/blob/main/docs/RESEARCH_PLAN.md)에 기록된 목표는 한국디지털콘텐츠학회 2026 추계종합학술대회 및 대학생논문경진대회다. [공식 안내](https://dcs.or.kr/homepage/custom/submit)를 2026-10-19 재확인했다. 제출 마감은 2026-10-26, 원고는 2단 1~2쪽, 대학생 부문은 포스터 발표이며 행사는 11월 19~20일이다. 이 분량과 일정에 맞춰 검증할 핵심 질문 하나로 범위를 좁힌다. 구체적인 심사 기준과 채택 여부는 이 안내만으로 확정할 수 없으며 제출·등록은 별도 작업이다.

**추가 주제 검토 보류:** 양자화 영향은 주제 후보에서 제외했다. Soft gate의 역전파 유무 비교는 [선행연구 검토](SOFT_GATE_REVIEW.md)에 근거를 기록했다. ToDi·CaRE·SDAR의 기존 분석과 겹치며 우리 조건의 생성 성능 이득은 미검증이다. 사용자는 기존 모델 평가를 계속하며 주제를 검토하기로 했으며 새 KD 비교나 추가 학습은 시작하지 않는다.

**SFT 절차 검토:** 완료한 예비 v1은 두 LR·3 epoch·개발 NLL 선택의 비교다. MiniLLM의 SFT 기준 모델 탐색과 증류 전 학생 초기화를 분리하는 원문 절차를 검토 중이며, 선정 조합의 새 실행 protocol은 아직 확정하지 않았다. [원문 설정·600 model-epoch 산출·적용 한계](DOLLY_SFT_MODEL_SELECTION.md#minillm-원문-절차와-적용-범위-검토)를 확인하고 기존 결과와 구분한다.

현재 흐름은 **Dolly SFT → 모델별 체크포인트 선택 → 생성·보조 평가 → 결과와 오류 비교 → 교사·학생 조합 선정 → 증류 방식 비교**다. 학습은 Dolly만 사용하고, 예비 생성 평가는 Dolly 500문항으로 수행하고 외부 3종은 후보 축소 후 적용한다. 2026-10-19에 4계열·8모델의 독립적인 예비 LoRA SFT와 Dolly 생성 평가를 완료했다. 후속 GPT-2·OPT 4모델의 SFT 외부 생성·보완 채점·분류 진단도 완료했다. 현재 후보 원본의 동일 평가를 진행하며 본 KD와 실제 공동 GPU 점검은 미실행이다. [원문 근거와 오류 사례](QUALITATIVE_REVIEW.md)에서 지시 따르기·사실 오류·과잉 추출을 구분한다.

검증 NLL은 각 모델의 학습률·체크포인트 선택 기준이다. ROUGE-L은 논문과 비교하는 1차 생성 지표이며 이것만으로 최종 조합을 확정하지 않는다. 2026-10-18 사용자 결정에 따라 원본/SFT 전후 기준선, METEOR·BERTScore·Distinct-4, 후보의 ECE·기존 분류 지표를 추가 실행한다. Dolly 원본/SFT 16조건·8,000개 응답의 보완 채점과 검증을 완료했다. 원본 8모델의 Dolly 생성 기준선을 완료했고 [원본/SFT 비교표](../results/model_selection_v1/REPORT.md)에 반영한다. 실행 명세는 [Dolly SFT 비교 계획](DOLLY_SFT_MODEL_SELECTION.md), 선정 절차는 [생성 평가 계획](GENERATION_EVALUATION.md)을 따른다.

## 1. 목적과 원칙

양자화 조건 분담: 다른 팀원이 비양자화 SFT를 진행하며, 현재 컴퓨터는 기존 BF16/NF4 정책의 8개 모델 실행을 계속한다. 동일 조건 대조·정밀도 기록·외부 결과 분리 원칙은 [공통 실행 지침](EXPERIMENT_GUIDE.md#양자화-조건의-역할-분담)을 따른다. 양자화 비교를 추가해도 현재 KD 방법 비교의 연구 목적은 유지한다.

현재 반복 수 결정: **모델 선정 단계의 네 생성 평가는 공통 seed 10 한 개**, 최종 선정 모델의 본 실험은 생성 seed 10/20/30/40/50의 5개 반복을 사용한다. 선정 평가에서 seed 간 표준편차는 계산하지 않는다. 기존 공개 SFT 모델의 5개 seed 평가 기록은 당시 결과로 유지한다. 학습 설정과 현재 실행 중인 학습은 이 변경으로 바꾸지 않는다.

Hinton으로 KD의 기초를, MiniLLM으로 생성 LLM 증류의 원리를 이해한다. 그다음 실행 가능한 범위에서 학생의 증류 전후 응답과 평가 결과를 관찰하고 문헌의 설명과 연결한다. 일차 목표는 원리 이해와 결과 해석이며, Dolly 공통 학습 조건에서 **KL 방향·Hard/Soft gate의 손실 적응과 Revival의 학습 갱신 거절에 따른 신호·분포·응답 차이**를 비교·시각화한다. 추가 기전 분석·새 방법 제안은 후속 탐구로 둔다. 이전 LightJudge의 `T=2`, rank, epoch, seed 등을 새 실험의 기본값으로 승계하지 않는다.

**진행 흐름은 기초 이해 → MiniLLM의 KL·CaRE의 gate/Revival 분석 → 손실 적응·갱신 거절의 비교 실험과 시각화다.** MiniLLM의 원래 언어·모델·데이터·초기 학습·평가 조건을 먼저 검토하되 전체 재현을 필수 목표로 삼지 않는다. 이번에 구현할 방법과 원문과의 차이를 명시한다. **CaRE의 gate와 Revival은 모두 현재 비교의 직접 근거이며 한국어 적용은 후속 탐구로 둔다.** 전체 모델 조합·benchmark를 수행할지는 자원과 확인 가능한 설정에 따라 별도로 정한다.

**연구의 중심은 참고문헌의 인사이트를 근거 자료와 함께 인용하고, 현재 조건에서 적용·검증하는 것이다.** 수식·그래프·표·사례가 어떤 주장을 뒷받침하는지 먼저 분석한다. 현재 목표에 필요한 응답 사례와 수행 지표를 선택하며, 효율성 순위나 비용 대비 점수를 목표로 두지 않는다. 메모리·실행 시간·저장 공간은 개인 컴퓨터에서 연구를 끝낼 수 있는지 판단하는 제약이다.

**근거 없는 숫자를 확정하지 않는다.** 다만 논문에서 사용한 값, 현재 조건에서 검증해 선택한 값, 비교를 정의하는 값은 서로 다른 근거를 갖는다. 다음을 혼동하지 않는다.

- **원문 재현값:** 원문 결과를 재현하기 위해 따르는 값. 새 조건의 최적값이라는 뜻은 아니다.
- **검증 선택값:** 사전에 정한 후보·예산·validation 기준으로 실제 선택한 값.
- **정의·대조값:** 무온도 변환이나 균등 혼합처럼 비교의 의미를 정의하는 값. 성능 최적값으로 부르지 않는다.
- **자원·통계 설계값:** GPU 예산, 반복 수, 목표 추정 정밀도 등. 논문이 정답을 주지 않으면 측정과 연구 목적을 근거로 별도 정한다.

모든 상황의 최적 T를 세 논문만으로 계산하는 공식은 확인되지 않았다. **현재 자료로 알 수 없는 값은 미정으로 남기는 것이 정확한 계획이다.** 탐색 구간·시험 예산도 설계 선택이므로 근거와 한계를 기록한다. 근거가 있다는 것과 최적성이 증명되었다는 것은 다른 주장이다.

## 2. 근거를 기록하는 방법

문서의 근거는 다음처럼 구분한다.

| 표시 | 의미 | 확정할 수 있는 범위 |
|---|---|---|
| P | 고정한 논문 버전의 주장·수식·설정·결과 | 논문에 기록된 해당 조건 |
| I | 공식 구현의 고정 commit에서 확인한 동작 | 해당 코드의 해당 경로 |
| D | 직접 유도한 수학적 사실 | 명시한 수학적 가정 아래 |
| M | 연구 방법론 문헌의 근거 | 선택·평가·비교 절차 |
| S | 이 연구를 위한 설계 제안 | 채택 이유와 검증 절차를 명시한 계획 |
| U | 아직 확인하지 못한 사실 또는 값 | 확정하지 않음 |

논문에 있다는 이유만으로 일반화하지 않고, 공식 코드의 기본값을 그 과제의 검증된 최적값으로 바꾸어 적지 않는다. 각 설정에는 **출처 위치 → 적용 조건 → 선택 이유 → 확인 결과 → 남는 한계**를 기록한다.

## 3. 주 참고문헌과 후속 참고의 근거

P1–P4와 P5의 gate·Revival은 현재 비교의 중심 근거다. P6–P7에서 confidence·BALD·gate·거절 규칙과 설정을 확인한다. 조건부 calibration·오류 보호 주장은 관측과 구분해 해석하며 전체 분석을 자동으로 재현 목표에 넣지 않는다.

| ID | 근거와 원문 위치 | 연구에서 확인할 것 | 현재 허용하지 않는 해석 |
|---|---|---|---|
| P1 | [Hinton, §2·§2.1](https://arxiv.org/pdf/1503.02531v1): 온도·soft CE·그라디언트 | 낮은 확률의 관계와 학습 신호의 크기가 어떤 역할을 하는가? | T를 높이면 오류가 교정되거나 모델 용량이 늘어남 |
| P2 | [Hinton, §3·§4.1](https://arxiv.org/pdf/1503.02531v1): 모델·과제별 다른 T 관측 | 학생의 표현 제약과 T 효과를 함께 읽기 | 다른 과제에 동일한 최적 T가 보장됨 |
| P3 | [MiniLLM, §2.1–2.3](https://arxiv.org/html/2306.08543v4): 시퀀스 RKL·policy gradient·안정화 | 손실 방향과 학습 prefix의 출처를 함께 확인 | 한 답 위치의 RKL만 사용해 전체 MiniLLM을 재현함 |
| P4 | [MiniLLM, §3.1·Appendix B.1](https://arxiv.org/html/2306.08543v4): validation 선택·SFT 단계·보존 손실 | 초기화와 checkpoint 선택까지 일치시키기 | 모델·데이터 이름만 같으면 같은 학습 조건 |
| P5 | [CaRE, §2·§3.1](https://arxiv.org/html/2609.36734v1): gate·Revival·selection gradient | 어떻게 배울지와 갱신을 받을지 분리 | gate 전환 자체가 교사의 실제 오답을 거절함 |
| P6 | [CaRE, §3.3–3.4·부록 C/G](https://arxiv.org/html/2609.36734v1): 조건부 entropy·calibration | 가정이 관측 조건에서 타당한지 확인 | 낮은 entropy가 곧 정답이거나 실제 ECE 최적성 |
| P7 | [CaRE, §4.5·부록 D.3](https://arxiv.org/html/2609.36734v1): sampling 온도·margin·MC 수 | 각 값의 역할과 ablation 조건을 기록 | sampling T=3을 KD 온도의 최적값으로 사용 |
| M1 | [Cawley·Talbot, 2010](https://jmlr.org/papers/v11/cawley10a.html): model selection의 과적합과 선택 편향 | 선택 자료와 최종 평가 자료를 분리 | 반복해서 본 test에서 설정을 고른 뒤 독립 평가라고 부름 |
| M2 | [Bergstra·Bengio, 2012](https://jmlr.org/papers/v13/bergstra12a.html): hyperparameter 탐색 | 탐색 영역·예산·선택 기준을 공개 | search를 사용했다는 사실만으로 전역 최적을 주장 |

위 표는 논문별 적용 질문이다. 세 논문의 구성요소를 모두 합치는 것이 연구 주제라고 미리 정하지 않는다.

## 4. 주 참고문헌 분석과 보관한 후속 참고

### 4.1. Hinton: 무엇을 전달하는가?

읽기 자료: [한국어 해설](../papers/01_hinton_2015_ko.md), P1–P2.

분석 결과로 다음을 설명할 수 있어야 한다.

1. 교사의 soft target과 실제 정답의 역할.
2. T가 같은 logits의 분포와 그라디언트에 미치는 변화.
3. 동결한 교사에서 soft CE와 FKL의 학생 그라디언트가 같은 조건.
4. 높은 온도·중심을 맞춘 logits에서 T² 보정이 나오는 근사.
5. 교사의 작은 확률이 정보인지 잡음인지에 대한 경험적 질문.

**통과 기준:** 수식을 따라 신호를 설명하고, 정답과 교사 예측이 충돌하는 예시를 설명할 수 있다. 수식의 가정과 해당 실험의 관측을 구분한다. 통과 전에는 온도 값을 정하지 않는다.

### 4.2. MiniLLM: 어디에서 만든 응답으로 배우는가?

읽기 자료: [한국어 해설](../papers/02_minillm_2024_ko.md), P3–P4.

분포의 좌표가 토큰인지 응답 전체인지, 기대값의 표본이 교사·학생·혼합 중 무엇인지 표시한다. policy gradient의 필요성, single-step 분해, teacher-mixed sampling, 길이 정규화를 각각 어떤 문제에 대응시키는지 정리한다. 일반 능력 보존 손실과 SFT 초기화도 학습 과정에 포함한다.

**통과 기준:** FKL/RKL의 방향 변경과 prefix 변경을 서로 다른 조작으로 설명할 수 있다. 원문 Phase 1의 checkpoint 선택과 Phase 2의 선택을 구분한다. 생성 반복 수를 독립 학습 반복 수로 취급하지 않는다.

### 4.3. CaRE: 손실을 바꾸는 것과 학습 갱신을 거르는 것은 어떻게 다른가?

현재 분석 대상은 confidence 정의·KL 혼합·Hard/Soft gate의 차이와 BALD 기반 Revival의 수용·거절 규칙이다. 두 구성요소의 개별 역할과 결합을 구분한다. 조건부 calibration과 실제 오류 보호·정답성의 근거는 별도로 확인한다.

읽기 자료: [한국어 번역·분석](../papers/03_care_kd_2026_ko.md), P5–P7.

confidence의 측정 공간, hard/soft 수식, selection gradient, BALD·Revival의 조건을 정리한다. entropy의 뾰족함, 실제 정답, epistemic uncertainty, 지도 신호의 유용성을 다른 개념으로 적는다. 정리의 가정과 보고한 ECE의 한계를 함께 읽는다.

**통과 기준:** gate-only와 전체 CaRE-KD를 구분하고, soft/hard 사이에서 동시에 달라지는 요소를 설명한다. 원문 수식·그림·표·설명의 불일치를 공식 구현 확인 사항으로 남긴다.

자료의 출처는 다음처럼 표시한다.

- **원문 자료 인용:** 원저자의 결과로 표시하고 출처를 연결한다. 이미지 재게시·변형은 해당 자료의 이용 조건을 확인한다. 현재 Hinton·MiniLLM 그림은 원문 링크로 연결하며, CaRE 자료 재사용에는 CC BY 4.0의 출처·변경 표시를 유지한다.
- **원문 수치 재작성:** 표의 정확한 수치로 그렸는지, 그림을 digitization해 근사했는지 밝힌다. 없는 점·오차막대·원자료를 임의로 보충하지 않는다.
- **수식 기반 설명 그림:** 사용한 수식·가정·예시값의 목적을 밝히고 학습용 예시로 표시한다. 설명용 수치를 실험 최적 설정이나 원문 실측으로 취급하지 않는다.
- **우리의 실험 자료:** 선정한 모델·데이터·설정과 원자료·분석 절차를 연결한다. 문헌 결과와 별도로 표시한다.

이 단계의 산출물은 원리별 근거 목록과 인용 가능한 자료 목록이다. 확정한 탐구 목표에 맞춰 실험 범위를 정한 뒤 필요한 시각화만 선택한다.

## 5. 확정한 탐구 목표와 진행 범위

### 5.1. 목표: 생성형 언어모델의 지식증류 원리와 학생 모델의 응답 변화 탐구

[결정: 2026-10-15, 범위 구체화] **같은 교사·학생과 선정한 공통 데이터에서 KL 방향·Hard/Soft gate의 손실 적응, Revival의 학습 갱신 거절, 두 장치의 결합을 비교·시각화한다.** Hinton은 기초, MiniLLM은 KL 방향, CaRE는 손실 적응과 선택적 갱신의 직접 근거다. SFT·SeqKD·MiniLLM 전체 알고리즘을 넓게 비교하는 것으로 주제를 확장하지 않는다.

핵심 질문은 **‘같은 생성 학습 조건에서 손실을 어떻게 바꿀지 결정하는 것과 학습 갱신을 받아들일지 결정하는 것은 각각 어떤 역할을 하며, 둘을 결합하면 학생의 학습·분포·응답이 어떻게 달라지는가?’**다. 구체적인 주제명은 **‘생성형 LLM의 지식증류에서 손실 적응과 선택적 학습 갱신의 역할 비교’**로 둔다.

[용어] 흔히 사용하는 지식 유형 분류는 응답/출력 기반·특징 기반·관계 기반이다. 확률분포 기반 KL 증류는 응답/출력 기반에 포함된다. 이 탐구는 그 안에서 목적함수와 gate를 비교한다. [Gou 외, Knowledge Distillation: A Survey, §2](https://arxiv.org/pdf/2006.05525v7).

| 문헌 | 현재 역할 | 연결할 내용 |
|---|---|---|
| [Hinton](https://arxiv.org/pdf/1503.02531v1) | KD의 기초를 이해하는 주 참고문헌 | soft target·온도·교사와 학생의 출력분포, 전달 신호 |
| [MiniLLM](https://arxiv.org/html/2306.08543v4) | 생성형 LLM 증류를 탐구하는 중심 참고문헌 | 생성분포·KL 방향·학습 응답의 출처, 원문 학습 과정과 응답 평가 |

### 5.2. 기초·분석·실험의 역할

| 단계 | 할 일 | 산출물 |
|---|---|---|
| 1. 기초 이해 | 다음 토큰 예측과 문장 생성, 교사·학생, 확률분포·soft target·온도·CE/KL 이해 | 생성과 증류 과정을 자기 말과 간단한 예시로 설명 |
| 2. 논문 분석 | Hinton의 기초, MiniLLM의 KL, CaRE의 gate·Revival과 수식·그림·표 연결 | KL·손실 적응·갱신 거절의 의미와 조건을 설명하는 자료 |
| 3. 제한된 실험과 해석 | 원문 구성을 검토해 실행 범위를 정하고 모델·데이터·설정을 선정한 뒤 응답·평가 결과 관찰 | 실행 조건, 증류 전후 응답 사례와 평가 결과, 문헌과 연결한 해석·한계 |

현재는 Dolly 공통 분할·SFT 학습 명세를 동결하고 4계열·8모델을 비교한다. **어떤 입력·SFT 학생 초기 상태·증류 방법을 비교하고 응답의 무엇을 관찰할지**를 본 KD 전에 확정한다. SFT 이후 모델 선정까지의 단계는 §6.1을 따른다. 최종 조합·본 KD 설정은 미정이며 별도 시간 제한은 없다.

응답의 과제 적합성·지시 준수·길이·오류 사례 등은 관찰 후보이며 전부 분석하기로 확정한 목록은 아니다. 선정 과제에 맞는 지표와 채점 근거를 정하고 정량 결과와 실제 응답 사례를 함께 읽는다. 사례만으로 전체 성능의 개선을 단정하지 않는다.

MiniLLM 전체 재현은 필수 목표가 아니다. 단순한 증류 실험이나 일부 요소만 적용한다면 실제 방법·선정 이유·원문과의 차이를 기록한다. RKL 손실만 적용한 실험을 MiniLLM 전체 재현이라고 부르지 않는다. T 등은 원문 사용값과 새 조건에서 검증해 선택한 값을 구분한다.

일차 완료 기준은 **생성·증류 원리를 설명하고, 문헌 근거와 실행 조건을 제시하며, 관찰한 응답 변화와 평가 결과를 해석하는 것**이다. 새 방법 제안·한국어 적용은 결과를 본 뒤 필요할 때 검토할 후속 탐구다. Hard/Soft gate와 Revival 비교는 현재 목표에 포함한다. 새로운 기전 가설을 먼저 확정할 필요는 없다.

### 5.2.1. 핵심 비교: FKL / RKL / Hard gate / Soft gate

같은 context와 어휘 좌표에서 교사·학생 분포를 P와 Q라고 하고, 공통 표현을 다음과 같이 둔다.

$$
D_F=KL(P\|Q),\qquad D_R=KL(Q\|P),\qquad L_g=gD_F+(1-g)D_R.
$$

[문헌·설계] 아래 네 조건은 고정 KL 방향과 CaRE의 gate를 구분해 비교하는 틀이다. FKL/RKL은 고정 목적함수이고 Hard/Soft는 두 목적함수를 입력별로 선택·혼합하는 규칙이므로 독립적인 2×2 요인 실험이라고 부르지 않는다. [MiniLLM §2](https://arxiv.org/html/2306.08543v4), [CaRE §2.1·3.1](https://arxiv.org/html/2609.36734v1).

| 비교 조건 | gate의 역할 | 핵심 관찰 |
|---|---|---|
| Forward KL | g=1로 고정 | 해당 입력에서 교사의 확률질량을 맞추는 학습 신호와 학생의 분포 변화 |
| Reverse KL | g=0으로 고정 | 같은 조건에서 방향을 바꾸었을 때의 신호·분포·응답 차이 |
| Hard gate | confidence 차이에 따라 g가 0 또는 1 | 토큰별로 어느 KL이 선택되는지, 경계 부근의 선택·갱신 변화 |
| Soft gate | confidence 차이에 따라 g를 연속적으로 결정 | KL 혼합 비중과 gate를 통한 미분, 분포·응답 변화 |

CaRE 식 (3)의 기준 정의는 c(P)=1−H(P)/log|V|, Δc=c(P)−c(Q), g_hard=1[Δc≥0], g_soft=σ(Δc−m)이다. **Hard/Soft는 gate의 구분이며 hard label/soft target의 구분과 다르다.** m·추가 scale·온도는 아직 새 실험 값으로 확정하지 않았다. 식 (3)과 Figure 2의 scale 차이를 공식 구현과 대조하며 임의의 계수를 추가하지 않는다.

[설계] 공통 teacher·student 초기 checkpoint, 선정 데이터 revision·분할, tokenizer·학습 mask, 학습량·optimizer·평가 조건을 기록한다. prefix를 reference/teacher/student 중 어디서 얻는지 먼저 정하고 네 조건에서 동일한 학습 규칙을 사용한다. 학생 rollout으로 입력이 이후 달라질 때는 같은 입력의 고정 진단과 자유 생성 결과를 구분한다. 단순 토큰 RKL 비교를 MiniLLM 전체 재현으로 표시하지 않는다.

**원문의 Hard/Soft 방법 비교와 연속성 하나의 효과를 구분한다.** 원문은 margin·연속 혼합·gate의 미분 여부가 함께 달라진다. 우선 정의한 방법의 차이를 비교하고, 결과를 연속성 하나의 인과 효과로 단정하지 않는다. 추가 대조는 후속 해석에 필요한 경우에만 검토한다. Revival은 별도의 수용·거절 축으로 §5.2.2에서 비교한다.

| 시각화 [설계] | 설명할 내용 | 표시 조건 |
|---|---|---|
| FKL/RKL 분포·학습 신호 | 같은 입력에서 확률을 옮기는 방향과 토큰별 차이 | 같은 prefix·온도·어휘 좌표. 설명용 분포와 실제 모델 관측을 구분 |
| confidence 차이와 gate 곡선 | Hard의 분기, Soft의 혼합 비중 | 실제 margin·scale·미분 설정과 confidence 정의 표시 |
| 토큰별 heatmap | Δc·g·KL·갱신 신호가 위치에 따라 어떻게 변하는가 | 같은 진단 입력·mask, 전체 어휘에서 계산한 값의 표시 범위 명시 |
| 학습·평가 추이 | 공통 validation 지표와 각 조건의 동작 | 학습량과 표본·변동을 표시. 서로 다른 학습 loss를 성능 순위로 해석하지 않음 |
| 생성 응답 비교 | 같은 평가 입력에서 내용·길이·반복·과제 수행 차이 | 생성 조건·사례 선정 이유와 실패·무변화도 기록 |

모델의 우선 검토 조합은 원문에 있는 **Dolly로 준비한 GPT-2 1.5B 교사 → 120M급 학생**이다. [모델 검토 §2.1](MODEL_BENCHMARK_REVIEW.md)에 근거와 확장 후보를 정리했다. 기반 모델 GPT-2 XL/base의 revision·tokenizer 일치와 짧은 공통 입력 추론은 §6.4에서 확인했다. 공개 Dolly-SFT는 별도 평가했고 기반 XL/base의 일회성 optimizer 갱신은 통과했다. 새 데이터별 본 SFT와 장기 안정성은 미검증이다. 공통 자료 구성은 [데이터 선정 문서 §4.1](DATA_SELECTION.md)을 따른다.

### 5.2.2. 중심 비교: 손실 적응과 학습 갱신 거절

[문헌] CaRE-Divergence는 단일 forward의 정규화 entropy confidence로 토큰별 FKL/RKL 선택·혼합을 바꾼다. Revival은 MC dropout으로 추정한 교사·학생 BALD와 각각의 과거 분포 quantile을 사용해 갱신을 억제한다. **두 장치는 사용하는 신호와 개입 위치가 다르다.** 단일 entropy confidence를 그대로 Revival의 불확실성으로 대체하지 않는다. [CaRE §2.1–2.2·식 (1)–(6)](https://arxiv.org/html/2609.36734v1).

[설계] 같은 손실에서 Revival 유무를 대조해야 갱신 거절의 역할을 읽을 수 있다. gate와 Revival을 동시에 켠 결과만 기준선과 비교하면 두 효과를 분리할 수 없다. 아래는 구성요소를 구분하는 대조 구조이며, 모든 FKL/RKL/Hard/Soft × Revival 조합을 실행하기로 확정한 목록이 아니다.

| 대조 구조 | 손실 | Revival | 확인할 역할 |
|---|---|---|---|
| 고정 기준선 | FKL 또는 RKL | 없음 | 고정 KL 방향의 학습·분포·응답 |
| 손실 적응만 | Hard 또는 Soft gate | 없음 | 어떤 KL로 배울지를 바꾸는 효과 |
| 갱신 거절만 | 대응 기준선과 같은 고정 KL | 있음 | 같은 손실에서 지도를 수용·거절하는 효과 |
| 두 장치 결합 | 대응 조건과 같은 Hard/Soft gate | 있음 | 같은 gate에 거절 규칙을 추가한 변화와 구성요소의 결합 |

고정 KL·gate별 대응 조건은 원문 설정 확보와 실제 자원 확인 후 확정한다. 위 대조는 [CaRE §4.3·Table 2의 Revival 유무 비교](https://arxiv.org/html/2609.36734v1#S4.T2)를 참고한 우리 설계이며 원문이 이 표의 모든 조합을 동일 조건으로 실행했다고 표시하지 않는다.

시각화에는 **토큰별 gate·손실 변화**, **교사/학생 BALD와 거절 mask의 시간 흐름**, **수용·거절된 자료의 category·길이·불확실성 분포**, **같은 손실에서 Revival 유무에 따른 공통 평가·응답 변화**를 연결한다. 처리한 입력 수와 실제 갱신 수를 함께 기록한다. 거절됐다는 사실을 실제 오답·유해한 지도의 판정으로 바꾸어 해석하지 않는다.

실행 전에는 MC dropout이 해당 모델에서 유효한 비퇴화 신호를 만드는지, 원문의 추정·mask 집계 단위가 무엇인지, 거절 시 실제 optimizer 갱신이 어떻게 처리되는지 확인한다. loss·gradient를 0으로 만드는 것과 optimizer step 생략은 구분한다. MC 수·dropout·온도·quantile·schedule은 원문 역할별 근거와 구현·자원 확인 전까지 미정으로 둔다. 단일-pass 대체 추정량을 쓰면 그 가정과 변경을 명시한다.

### 5.2.3. 단계별 시각화 구성

현재 모델 선정에서는 4계열의 생성 점수·교사−학생 차이를 같은 축으로 비교한다. 본 증류 시각화는 선정한 한 조합에서 아래 순서로 진행한다. GPT-2 XL/base의 최초 동시 적재 점검은 과거의 실행 근거이며 현재 후보를 두 모델로 제한하는 결정이 아니다.

| 순서 | 관찰할 내용 | 다음 단계로 넘어갈 근거 |
|---|---|---|
| A. 두 모델 준비 | revision 고정, GPU 동시 적재, tokenizer·어휘 ID 대조, 같은 입력의 유한 logits | 적재·추론 확인 기록. 학습 성공이나 교사 지도의 유익성 검증과 구분 |
| B. 분포 비교 | 같은 prefix에서 교사·학생의 다음 토큰 확률과 차이 | 기반 모델의 추론 점검용 표시임을 명시. 선정 데이터의 SFT 후에는 그 checkpoint로 다시 계측 |
| C. 손실 적응 | FKL/RKL·confidence·Hard/Soft gate를 연결 | 공통 초기 상태·학습 context·온도·margin·scale·미분 경로의 근거 확인 |
| D. 갱신 거절과 결합 | MC-BALD·과거 quantile·수용/거절·실제 갱신 | Revival 구현과 대응 조건 검증 후 추가. 학습·평가 결과와 연결 |

[설계] 시각화마다 한 질문을 다루고, 교사·학생 색상과 대응 패널의 축·토큰 순서를 고정한다. 분포 비교, gate 곡선, Revival 흐름을 별도 그림으로 나눠 읽는다. 실제 학습 결과가 없는 단계에서 학습 전후 변화나 방법별 우열을 표시하지 않는다.

- 표시 토큰은 교사·학생의 주요 토큰 합집합을 같은 순서로 사용하고, 빠진 확률은 `기타 어휘`로 합산한다. 표시할 토큰 수는 가독성을 위한 표시 설정이며 선택 근거와 실제 수를 캡션에 남긴다.
- KL·entropy는 전체 어휘에서 계산한다. 화면에 보이는 토큰만 다시 정규화한 값을 원래 분포의 진단값으로 사용하지 않는다. `기타 어휘`는 어휘를 묶은 표시이며 개별 토큰이 아니다.
- 확률은 대응 패널에서 같은 척도, 차이는 0을 중심으로 표시한다. heatmap은 비교 패널에 공통 범례·범위·mask를 쓰고 범위 밖 값이 있으면 명시한다.
- 캡션에는 입력·prefix 위치·checkpoint 단계·revision·정밀도·온도 변환·계산 범위를 적는다. 문헌 그림, 수식 예시, 기반 모델 추론 점검, 선정 데이터의 SFT 후 실측을 구분한다.
- 초기에는 공통 입력의 마지막 위치 logits만 로컬에 보관한다. 전체 학습 토큰의 logits 저장은 필요한 관측과 저장량을 확인한 뒤 결정한다. 가중치·cache는 Git에 올리지 않고 실행 코드·작은 확인 기록만 공유한다.

### 5.3. 후속 연구 범위

한국어 적용, UltraChat·MetaMathQA의 별도 SFT, 코드·수학·다중 턴 과제 확장과 교사 응답 증강은 현재 8개 모델 선정의 완료 조건에 포함하지 않는다. 현재 문헌 분석과 Dolly 실험 결과를 정리한 뒤 별도로 검토한다.

한국어 자료의 조사 근거는 [데이터 후보 문서](DATA_SELECTION.md)에 보관한다. 원생·번역·합성 자료의 제작 과정과 같은 원문에서 나온 group을 구분하고, 한국어 채점·tokenizer·실행 가능성을 확인한 뒤 새 실험을 설계한다.

## 6. 모델·데이터 선정 절차

학습 데이터는 Dolly로 확정했다. 현재는 데이터를 다시 고르는 단계가 아니라 **같은 Dolly로 준비한 모델 중 본 증류 실험의 교사·학생 조합을 고르는 단계**다. MiniLLM·CaRE의 생성 평가 흐름을 참고하되 원문 전체 재현으로 표시하지 않는다.

### 6.1. SFT 이후의 단계와 산출물

| 순서 | 작업 | 완료 근거 |
|---|---|---|
| 1. 모델별 체크포인트 선택 | 같은 모델의 두 LR 후보·epoch별 개발 NLL 비교 | 완료된 두 LR JSON, 선택 adapter와 hash. 다른 tokenizer의 NLL로 계열 순위를 정하지 않음 |
| 2. 예비 생성 평가 | 활성 8모델의 Dolly 500문항에 직접 응답 | 같은 ID·생성 seed 10·명세, Dolly 점수와 문항별 기록 |
| 2.1. 원본 기준선 | 활성 8개 원본의 같은 Dolly 500문항 추론 평가 | 같은 model revision·정밀도·prompt·seed·ID, 원본/SFT/변화량 표. 기존 SFT·응답 재사용 |
| 3. 보완 지표 | 원본/SFT의 METEOR·BERTScore·Distinct-4 채점 | 원본/SFT 16조건·8,000개 응답의 실제 채점·검증 완료. 길이·다중 정답·집계 고정, 추가 SFT 불필요 |
| 4. 후보 후속 평가 | 후보 축소 후 원본/SFT의 외부 3종·SST-2·BoolQ | GPT-2·OPT SFT 4모델 완료, 원본 진행 중. 생성 지표와 accuracy·macro-F1·클래스별 오류·Brier·ECE. 기존 완료 결과 재사용 |
| 5. 비교·오류 분석 | 모델×benchmark×지표 표, 계열 내 교사−학생 차이, 실제 응답 오류 확인 | 과제별 우위의 일관성, 지시 준수·사실 오류·반복·누락과 사례 선정 근거 |
| 6. 증류 실행 점검 | 후보 조합의 같은 어휘 좌표·prefix·학생 갱신과 필요한 생성 경로 확인 | 실제 forward/backward·메모리·step 시간. 적재 성공만으로 판정하지 않음 |
| 7. 조합 선정 | 성능·오류 특성·연구 목적·실행 가능성의 근거 종합 | 모델 ID·revision·SFT adapter hash·정밀도·선정 자료·이유와 한계의 동결 |

자동 worker는 모델마다 **예비 SFT → 문서 → Dolly 500 생성 → 생성 보고서·문서 → 다음 모델**을 수행한다. 보완 지표·오류 검토·증류 실행 점검·최종 조합 선정은 이 자동 실행의 완료와 별개다. 8모델의 Dolly 예비 평가 파일이 모두 생겼다는 사실만으로 최종 조합이 선택되지는 않는다.

Gemma-2-9B-IT까지 끝나면 위 후속 평가와 추천 조합 보고까지 이어간다. 이번 추가 실행은 평가이며 새로운 SFT 탐색·본 KD 학습은 시작하지 않는다. `SFT − 원본`과 이후의 `KD 학생 − 동일 SFT 학생`, 교사−학생 격차를 구분한다. MiniLLM 원문의 전체 SFT 탐색·학생 초기화는 선정 이후 별도 설계로 남긴다.

### 6.2. 현재 모델과 자료

| 계열 | 교사 후보 | 학생 후보 |
|---|---|---|
| GPT-2 | XL | base |
| OPT | 2.7B | 125M |
| OpenLLaMA | 7B | 3B |
| Gemma-2 | 9B-IT | 2B-IT |

고정한 model ID·revision·LoRA·정밀도·전처리는 [현재 SFT 명세](DOLLY_SFT_MODEL_SELECTION.md)를 따른다. GPT-2·OPT·OpenLLaMA의 pretrained 상태와 Gemma-IT의 post-training 이력, template·어휘·정밀도가 다르므로 결과를 순수한 모델 구조나 양자화 하나의 효과로 해석하지 않는다.

공통 학습 11,117건·개발 검증 975건·Dolly 선정 평가 500건은 `MiniLLM/dolly` 고정 revision에서 준비했다. 원문 응답을 자르거나 모델마다 행을 다시 선정하지 않는다. 추가 세 benchmark는 학습 자료가 아니라 생성 일반화의 평가 자료다. 총 2,516문항의 배포 revision·다중 정답·길이·누수 점검은 [생성 평가 명세](GENERATION_EVALUATION.md)에 기록한다.

UltraChat·MetaMathQA의 전체 구조·길이 감사는 [과거 데이터 비교 설계](DATASET_SFT_COMPARISON.md)에 보관한다. 해당 자료의 직접 SFT는 현재 실행 대상이 아니다.

### 6.3. 조합 선정의 판단과 실행 제약

최저 NLL·최고 분류 accuracy·최대 교사−학생 격차 중 하나로 자동 선정하지 않는다. 생성 과제별 일관성, 보완 지표와의 충돌, 동일 문항의 오류, white-box logits 접근과 어휘 대응, MC 신호·실제 학습 경로를 함께 검토한다. 임의의 최소 점수 차이나 지표 가중합을 만들지 않는다. 보완 지표의 채택·설정과 오류 검토 기준은 전체 결과를 보고 유리한 기준으로 바꾸지 않도록 먼저 문서화한다.

**2026-10-19 기준 보완:** 교사의 절대 성능과 응답 품질을 명시적으로 확인하며, 격차가 작다는 이유로 OpenLLaMA·Gemma를 제외하지 않는다. 최종 선정 대상은 4계열·8모델이다. GPT-2·OPT 네 모델은 현재 외부 후속 평가 범위이며 최종 후보 전체를 뜻하지 않는다. 현재 Dolly 지표에서 절대 성능이 가장 높은 Gemma-9B도 학생과의 적합성·공동 증류 실행 가능성을 확인할 후보로 유지한다. [선정 검토와 근거](DOLLY_SFT_MODEL_SELECTION.md#후속-후보와-검증-범위-2026-10-19)에 변경 이유와 사후 검토라는 한계를 기록한다.

**교사 품질 검증 선행:** 학습 11,117건을 모두 사용했다는 사실과 ROUGE-L 25.92만으로 교사의 실제 정답률이나 충분한 학습을 주장하지 않는다. 500건은 평가용이며 가중치 갱신에 사용하지 않았다. 현재 사실성·지시 준수의 정오 판정은 미완료다. 같은 문항에서 교사의 실제 응답과 학생 대비 수행을 검토하고, 필요한 교사 추가 준비·모델 변경 여부를 판단한 뒤 본 증류로 진행한다. 응답 유사도나 일회성 KD 연산 점검을 교사 품질 또는 증류 효과의 입증으로 대체하지 않는다. 기존 후보의 원본/SFT 추론 평가는 계속하되 품질 검증에 앞서 증류 학습을 시작하지 않는다.

현재 장비는 RTX 5060 Ti 전용 VRAM 16,311 MiB, RAM 31.62 GiB, Ryzen 5 7500F다. 현재 실행 환경과 장비별 점검은 [공통 실행 지침](EXPERIMENT_GUIDE.md)을 따른다. 단독 SFT가 가능해도 교사·학생·optimizer·logits·generation cache·MC forward가 함께 필요한 증류가 가능한지는 별도 확인한다.

평가 모델을 추가하는 BERTScore는 고정 model ID·revision·layer·길이 처리·다중 reference·집계를 먼저 명세한다. 평가 지표를 추가하기 위해 epoch를 늘리지 않는다. 완료 시간은 준비·학습·응답 생성·후처리 채점을 구분하고 실측한 경로에서만 추정한다.

### 6.4. 과거 관측과 현재 기준선의 구분

GPT-2 XL/base의 최초 동시 적재·짧은 입력 forward는 [모델 점검 기록](../results/model_preflight.json)에 있다. 이는 전체 증류 경로의 실행 확인이 아니다. 저자가 공개한 SFT checkpoint의 평가는 [공개 SFT 기준선](SFT_BASELINE_EVALUATION.md)에 별도 보관하며, 이번 직접 SFT 결과나 미학습 원본의 점수와 합치지 않는다.

2026-10-19에 같은 원본 revision·정밀도·prompt·문항·생성 조건으로 활성 8모델의 원본/SFT Dolly 500 비교와 보완 채점을 완료했다. [전후 비교표](../results/model_selection_v1/REPORT.md)에 실제 변화량을 기록한다. 현재 GPT-2·OPT 원본의 외부 후속 평가를 진행한다. SFT 전후 변화와 SFT 후 교사·학생의 차이, 본 KD 이후 학생의 개선은 별개의 대조다.

선정에 사용한 2,516문항을 독립적인 최종 test로 부르지 않는다. 본 KD 실험 전에 설정 선택 자료와 최종 평가의 역할을 정하고, 생성 5seeds 반복을 독립 학습 반복이나 독립 test의 대체로 해석하지 않는다.

## 9. 현재 조건에서 T를 선택하는 절차

**원문 조건의 실험을 선택한다면 해당 논문·공식 구현에서 확인한 값을 사용하고 출처를 기록한다.** 아래는 새 조건의 설정 선택이나 민감도 분석이 필요할 때 적용할 절차다. 온도 탐색 자체를 현재 탐구의 주제로 확정한 것은 아니다. 미확인 값을 임의로 채우지 않으며 원문 사용값과 현재 조건의 최적성 검증을 구분한다.

### 9.1. 무엇에 대한 최적값인지 먼저 정의

조건 c를 다음처럼 정의한다.

$$
c=(\text{교사·학생 checkpoint, 데이터·split, 출력 공간, prefix 출처,
손실, 학습 예산, 초기화, 평가 protocol}).
$$

[S] 선택 기준 S도 먼저 정한다. 기준 논문의 instruction following 재현은 해당 protocol의 validation ROUGE-L을 출발 근거로 삼을 수 있다. 사실성·정답성을 주 목표로 바꾸면 그 목표에 맞는 주 지표와 reference·judge 또는 채점 규칙의 근거를 별도 정한다. 서로 다른 보조 지표를 임의 가중합하여 새 종합 점수를 만들지 않는다.

$$
\widehat T_{c,\mathcal C,B}
=\arg\max_{T\in\mathcal C}\widehat S_{val}(\operatorname{Train}(c,T;B)).
$$

여기서 C는 사전에 정한 후보 집합 또는 영역, B는 탐색·학습 예산이다. 이 식은 **그 조건·후보·예산에서 validation 기준으로 선택한 값**을 뜻한다. 전체 양수 영역에서의 전역 최적 T 또는 다른 데이터의 최적값을 증명하지 않는다.

### 9.2. 후보 범위의 근거

원문이나 같은 조건의 공식 실행 설정에 탐색 범위가 있으면 위치와 적용 조건을 적는다. 새 조건에 그 범위를 옮길 때는 이식 가설임을 표시한다.

직접 관련된 KD T 범위가 없으면 미리 숫자를 만들지 않는다. 다음을 먼저 정리한다.

- 교사 logits의 차이와 entropy가 T에 따라 어떻게 달라지는가?
- 유효 출력 공간의 확률질량과 그라디언트가 어떻게 변하는가?
- 작은 확률의 정보가 어떤 표본에서 유익하거나 불안정한가?
- 어떤 T 영역을 검증할 수 있는 자원 예산이 있는가?

이 진단은 후보 설정의 근거를 보강하지만, entropy 곡선만으로 성능 최적 T를 결정하지 못한다. 영역의 상·하한, 확대 규칙, 표본 선정·시험 예산을 **test를 보기 전에** 문서로 정한다. 관련 근거를 확보할 수 없으면 본학습용 T 탐색은 보류한다.

**현재 상태:** Dolly 고정·4계열 8모델의 예비 SFT와 Dolly 생성 평가를 완료했고 원본/SFT 비교와 후보 검증으로 이어간다. 최종 교사·학생 조합은 미정이며 SFT 학습 명세는 동결돼 있다. T_KD 후보 범위와 시험 횟수는 미정이다. `{1,2,4,8}` 같은 편의적인 목록을 확정하지 않았다. 적재 점검에서 별도 온도 변환을 생략한 사실은 KD 온도 선택의 근거가 아니다.

### 9.3. 탐색 중 통제

T_KD를 비교할 때는 같은 데이터 입력·checkpoint 초기화·학습 예산·최종 평가 규칙을 사용한다. 학습률·정답 손실 비중·gate margin 등 결합된 변수는 통제하거나 사전 등록한 공동 탐색으로 처리한다.

고온 soft CE의 logit 그라디언트는

$$
\frac{\partial L}{\partial z_i}=\frac{Q_i^{(T)}-P_i^{(T)}}T,
\qquad
\frac{\partial L}{\partial z_i}\approx\frac{z_i-v_i}{NT^2}
$$

이므로 T 변화는 분포와 크기를 함께 바꾼다 [P1]. T² 보정의 가정을 적고 실제 gradient norm·clipping 빈도·hard/soft 신호의 상대 크기를 확인한다. T²가 모든 온도·손실·gate에서 동일한 최적화 조건을 보장한다고 가정하지 않는다.

[현재 gate 비교의 확인 사항] T_KD로 만든 분포를 confidence에도 사용하면 gate 자체도 달라진다. 이 효과는 논문식의 자연스러운 결합이지만, “온도 효과”와 “gate 규칙의 독립 효과”를 구분하는 연구에서는 별도로 설계해야 한다.

### 9.4. 선택 자료와 평가 자료

[M1, S] train은 파라미터 학습, development/validation은 hyperparameter·checkpoint 선택, 잠근 test는 최종 평가에 사용한다. 분할은 원문·공식 dataset의 근거를 따른다. 새 분할이 필요하면 정의·중복 검사·hash와 선택 이유를 먼저 기록하고 임의 비율을 기본값으로 넣지 않는다.

validation을 반복해서 사용하면 선택 기준에도 과적합할 수 있다. 선택한 후보는 독립 학습 반복으로 다시 확인하며, 가능한 경우 추가 development 확인 또는 외부 holdout으로 선택 안정성을 점검한다. nested selection이 필요하면 데이터·계산 예산을 따져 별도 설계한다. 이 계획이 아직 그 분할을 생성한 것으로 표시하지 않는다.

### 9.5. 방법별 튜닝을 공정하게 비교

다음 두 질문을 구분한다.

| 비교 | 목적 | T를 다루는 방식 |
|---|---|---|
| 원문 조건의 비교 | 문헌의 결과·현상을 재현하는가? | 검증 가능한 원문 설정을 따르고 최적성 주장은 하지 않음 |
| 각 방법의 검증된 성능 비교 | 같은 탐색 자원에서 어느 방법이 더 잘 수행하는가? | 방법별 설정 선택을 허용하되 영역·예산·실패 trial까지 공개 |

FKL에서만 고른 T를 모든 방법에 적용하고 그 결과를 각 방법의 최적 성능이라고 부르지 않는다. 반대로 방법마다 다른 T를 사용한 결과를 gate만의 인과 효과라고 부르지 않는다.

탐색 budget은 학습 횟수만으로 같다고 주장하지 않는다. rollout·teacher forward·MC dropout·평가를 포함한 자원 경계를 정하고, 실제 GPU 시간 또는 계산 예산의 근거를 기록한다. budget의 종류와 숫자는 하드웨어 실측 후 확정한다.

이는 설정 선택의 조건을 공개하고 로컬 실행 범위를 정하기 위한 기록이다. 계산 효율을 새 연구의 주 평가 목표로 바꾸는 근거가 아니다.

### 9.6. 어떤 결과를 최적값이라고 보고할 것인가?

독립 학습 변동과 평가 표본 변동을 구분해 선택 결과의 불확실성을 보고한다. 구분되지 않는 후보가 여럿이면 넓은 좋은 성능 구간 또는 선택의 불안정성을 함께 적는다. 차이가 검출되지 않았다고 동등성·전역 최적성을 선언하지 않는다.

후보 영역의 경계에서 가장 좋은 값이 나오면 전체 최적값처럼 보고하지 않는다. 예산과 사전 확대 규칙에 따라 탐색 영역을 재검토하고, 확대된 선택도 validation 단계에서 마친다.

최종 기록에는 c, C, B, 선택 지표, checkpoint 기준, 반복 정의, 각 trial 결과·실패, 선택한 T와 근처 민감도를 포함한다. 선택을 동결한 뒤 test를 평가하며, test 결과를 보고 T를 다시 골라 같은 test를 최종 근거로 사용하지 않는다.

### 9.7. 최소 training KL로 T를 고르지 않는 이유

[D] 유한 logits의 고정된 교사·학생 분포에서는 T→∞일 때 둘 다 같은 uniform 분포로 향하므로 보정 전 KL(P_T‖Q_T)도 0으로 향한다. 이것은 좋은 정답·생성 능력을 얻었다는 뜻이 아니다. T²를 붙여도 그 숫자는 과제 수행 지표와 동일하지 않다. **서로 다른 T·목적함수의 training loss 숫자만 비교해서 T를 선택하지 않는다.**

entropy, gate 비율, KL, gradient norm은 원인을 읽는 진단이고, 연구에서 정한 주 수행 지표의 validation 결과가 설정 선택의 근거다.

## 10. 단계별 설정의 근거 등록표

SFT에서 이미 고정한 값과 아직 정하지 않은 본 KD 설정을 구분한다. 실행 중인 SFT의 epoch·LR·batch·정밀도를 사후 변경하지 않는다.

| 항목 | 현재 SFT·선정 평가 | 본 KD에서 남은 결정 |
|---|---|---|
| 교사·학생 | 4계열·8모델의 고정 revision | 생성·오류·실행 근거로 한 조합과 adapter 선택 |
| 학습 데이터 | Dolly 11,117건, 개발 검증 975건 | 동일 학습 입력·mask·prefix 출처의 역할 확인 |
| 학습량·LR | 후보별 3epoch, LR 1e-4/2e-4, 모델 내부 NLL 선택 | KD의 학습량·LR·optimizer·scheduler·선택 기준 |
| Adapter·정밀도 | LoRA r64/alpha16/dropout0.05, BF16/NF4 정책 | 선정 조합의 실제 KD 경로와 학습 범위 |
| 무작위성 | 학습 seed 0, 선정 생성 seed 10 | 독립 학습 반복의 필요·예산. 본 생성은 10/20/30/40/50 |
| 생성 평가 | 예비 Dolly 500문항, 외부 3종은 후보 축소 후, 기존 sampling 명세 | 보완 지표·오류 검토·최종 평가의 역할 |
| T_KD·rollout 온도 | SFT에는 KD 온도를 적용하지 않음 | §7–9의 역할별 원문·구현·validation 근거 |
| Gate | 미적용 | confidence 공간·margin·scale·미분 경로 |
| Revival | 미적용 | MC 수·dropout·BALD·과거 quantile·schedule·mask·실제 갱신 |
| Teacher-mixed sampling·보존 corpus | 미적용 | 채택 여부와 원문 대비 변경 기록 |

원문 사용값·유한 후보의 검증 선택값·대조를 정의하는 값·자원 제약을 구분한다. 임의의 T 후보나 전역 최적성 주장을 추가하지 않는다. gate와 Revival의 미확인 사항은 [CaRE 분석](../papers/03_care_kd_2026_ko.md)과 공식 구현을 대조한다.

## 11. 응답 변화 탐구에 필요한 비교를 정한다

[S] 실험 방법을 정한 뒤 같은 학생 초기 상태·입력·평가 조건에서 증류 전후를 비교하는 계획을 세운다. 교사의 응답은 학생이 무엇을 배웠는지 해석하는 참고로 둔다. 다른 증류 방법을 추가 비교할지는 원문 근거·관찰 목적·실행 가능성에 따라 정한다.

- SFT 여부와 checkpoint를 기록한다. 서로 다른 초기 상태를 비교했다면 그 차이를 함께 밝힌다.
- 학습 입력·prefix 출처·손실·생성 조건·학습량을 기록한다. 여러 요소가 달라졌다면 한 요소만의 인과 효과로 해석하지 않는다.
- 과제에 맞는 정량 지표와 실제 응답 사례를 함께 제시한다. 사례를 고른 기준과 오류·무변화도 기록한다.
- 학습 loss 감소를 생성 응답 품질의 개선으로 바로 해석하지 않는다. 관찰 범위와 변동을 함께 보고한다.

현재 핵심 비교는 §5.2.1의 KL·Hard/Soft와 §5.2.2의 Revival 유무·구성요소 대조다. SFT 학생은 초기 상태의 참고 기준선이며 SeqKD·전체 MiniLLM 알고리즘 비교를 필수 실험으로 추가하지 않는다. Hard/Soft의 margin·미분 경로, Revival의 입력 노출·실제 갱신 차이를 기록하고 하나의 요소만의 효과로 단정하지 않는다.

## 14. 본 증류 실험의 미검증 사항

학습 prefix·rollout 출처, 온도 역할, gate의 공식 margin·scale·미분 경로, MC dropout의 비퇴화 신호, BALD·quantile·mask 집계와 optimizer 갱신 동작은 구현 전에 확인한다. T 후보 범위·시험 예산·독립 학습 반복·최종 평가의 역할도 아직 확정하지 않았다.

SFT의 NLL 감소나 교사의 생성 점수 우위만으로 증류 개선을 예측하지 않는다. 거절 여부·entropy·BALD를 실제 정오 판정으로 사용하지 않으며, 최종 성능과 기전 해석은 같은 초기 상태의 실제 KD 대조 결과가 있을 때 작성한다.
