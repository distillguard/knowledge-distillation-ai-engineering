# Dolly 모델별 SFT 진행

4개 계열·8개 모델의 예비 비교. 완료는 두 학습률 후보 학습과 검증 기반 adapter 선택을 모두 마친 상태다. 수치는 직접 실행한 결과만 기록한다.

Qwen 두 모델은 2026-10-16 범위 축소로 제외했다. 기존 결과·checkpoint는 보존하며 아래 완료 수와 현재 순위에는 포함하지 않는다. 원문 기반 SFT 탐색·학생 초기화·본 KD는 최종 한 조합 선정 이후의 별도 설계다.

| 모델 | 완료 LR 후보 | 선택 LR | 검증 NLL | 가중치 | 예비 Dolly 생성 | 기존 Dolly·분류 보조 평가 |
|---|---|---|---|---|---|---|
| GPT-2 base | 2/2 | 2e-04 | 2.2670 | BF16 | 완료 | 완료 |
| GPT-2 XL | 2/2 | 2e-04 | 1.7827 | BF16 | 완료 | 완료 |
| OPT-125M | 2/2 | 2e-04 | 2.1956 | BF16 | 완료 | 후속 |
| OPT-2.7B | 2/2 | 1e-04 | 1.6362 | BF16 | 완료 | 후속 |
| OpenLLaMA-3B | 2/2 | 2e-04 | 1.4170 | BF16 | 완료 | 후속 |

| Gemma-2-9B-IT | 2/2 | 1e-04 | 1.3214 | NF4 | 대기 | 후속 |

NLL은 각 모델 내부의 checkpoint·학습률 선택에 사용한다. 다른 tokenizer의 NLL로 성능 순위를 매기지 않는다.

각 모델 SFT 후 예비 Dolly 500문항을 먼저 평가한다. 외부 세 benchmark와 SST-2·BoolQ는 후보 축소 후 진행하며 이미 완료한 결과는 보존한다. Dolly 생성은 기존 응답을 검증해 재사용하며 중복 생성하지 않는다. 생성 seed는 10 한 개이고 seed 간 표준편차는 미추정이다.

[생성 벤치마크의 교사·학생 비교](../results/generation_benchmarks_v1/REPORT.md)

동일 Dolly의 원본/SFT 비교·보완 채점 후 유망 조합을 추리고 외부 생성 평가·보조 진단·오류 분석·KD 실행 점검으로 최종 조합을 선정한다. 선정 전 추가 SFT는 시작하지 않는다. METEOR·BERTScore·Distinct-4와 후보 분류의 ECE는 추가 실행 승인 상태이며 아직 채점 준비 중·미채점이다. 단계별 완료 기준은 [생성 평가 계획](GENERATION_EVALUATION.md#조합-선정까지의-단계와-완료-기준)을 따른다.
