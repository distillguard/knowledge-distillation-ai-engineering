# v2 결과 비교 요약

[문서 안내](../../README.md) · [계획서](RESEARCH_PLAN.md) · [보고서](RESEARCH_REPORT.md) · [비교 요약](RESULTS_VISUALIZATION.md)

연구 버전: v2

## 1 비교 설계

| 구분 | v1 | v2 |
|---|---|---|
| KD 반복 | 시드 10 | 시드 10·20·30 |
| KD 학습 예산 | 모든 단계 3에포크 학습 | 모든 단계 3에포크·1,419회 갱신 |
| 시험 가중치 | 검증 ACC 우선으로 에포크 선정 | 모든 증류 단계 E3 |
| 주 비교 | 단일 실행의 선정 모델 | 고정 E3의 시드별 결과와 평균·SD |
| 분석 보강 | 지표·대응 정오·혼동 분석 | 문항 부트스트랩·시드별 정확 McNemar·Holm·검증 추이 |

NLL·Brier는 v1에도 사용한 지표다. v2에서는 반복과 평가 시점을 통제하고 차이의 불확실성을 추가했다. 조건과 가중치 선정이 달라 두 버전의 수치 차이를 동일 모델의 성능 향상으로 해석하지 않는다.

## 2 최종 학생 세 시드 평균

| 조건 | ACC 평균 (%) ± SD (%p) | NLL 평균 ↓ | Brier 평균 ↓ |
|---|---|---|---|
| 직접 FKL | 65.2689 ± 0.0912 | 0.892186 | 0.470023 |
| 직접 RKL | 65.6639 ± 0.0949 | 1.106983 | 0.522328 |
| 중간 FKL | 65.1778 ± 0.1206 | 0.866428 | 0.459024 |
| 중간 RKL | 65.1626 ± 0.1147 | 1.112821 | 0.520646 |

## 3 결과를 읽는 순서

1. 중간 FKL의 NLL·Brier 평균은 직접 FKL보다 낮고, 대응 문항 차이의 개별 95% 구간도 0보다 낮다.
2. 직접 RKL의 평균 ACC가 가장 높지만 NLL·Brier는 SFT보다 높다.
3. ACC의 경로 차이 문항 구간은 0을 포함하고, 시드별 McNemar·Holm 결과도 정답률 차이를 확인하지 못했다.
4. 문항 구간은 고정된 세 학습 결과에 조건부다. 세 시드를 독립된 6,582문항으로 해석하지 않는다.

시드별 성능표, 24개 검정의 원·보정 p값, 검증 에포크 54개, 교사 오답 중첩과 비용 범위는 [연구보고서](RESEARCH_REPORT.md)에 제시한다. [공개 집계](../../artifacts/ecqa/kd_v2/publication_summary.json)에는 모든 모델·비교·지표의 개별 문항 구간이 있다.
