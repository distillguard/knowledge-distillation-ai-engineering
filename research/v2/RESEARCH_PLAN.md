연구 버전: v2


계획 기준일은 2026-10-27이며, 이 문서는 완료된 후속 실험의 설계와 분석 규칙을 정리한 공개본이다. v1의 검증 선정 모델 비교와 구분해, 공통 SFT 초기값에서 증류 경로와 KL 방향의 차이를 세 시드·고정 E3 조건으로 비교한다. 완료 결과는 [연구보고서](RESEARCH_REPORT.md)에 제시한다.

## 1 연구 목적과 피드백 반영

연구 질문은 ECQA에서 직접 경로와 2B 중간 교사 경로의 차이가 FKL과 RKL에서 어떻게 나타나며, 정답률과 선택 확률 품질의 결론이 일치하는지다. 연구 계획에 기록된 교수 피드백의 두 쟁점은 학습 반복에 따른 변동과 평가 가중치의 학습 시점 차이다. 피드백의 직접 인용이 아니라 실험 설계에 반영한 쟁점을 요약한다.

| 점검 항목 | 설계에 반영한 조건 |
|---|---|
| 학습 반복의 변동 | seed와 data_seed를 10·20·30으로 대응시켜 반복 |
| 평가 시점의 차이 | 모든 중간 교사·최종 학생 KD를 3에포크·1,419회 갱신한 E3로 평가 |
| 경로의 일관성 | 같은 시드·같은 KL 방향의 2B E3를 동결해 중간 경로의 교사로 사용 |
| 결과의 불확실성 | 평균·표본 SD, 대응 문항 부트스트랩, 정답 여부의 정확 McNemar 검정과 시드별 Holm 보정 |

통계 절차는 보완 분석으로 정한 것으로 교수 피드백의 직접 지시로 표현하지 않는다. 기존 시드 10의 결과를 관찰한 뒤 만든 후속 설계이므로 전체 실험을 새로운 맹검 사전등록 연구로 부르지 않는다. 시드 20·30은 규칙을 고정한 뒤 실행했다.

## 2 자료와 공통 초기값

ECQA의 질문·A–E 선택지·정답·사람 설명을 사용한다. 분할 간 동일 ID·정규화 질문을 test→dev→train 우선순위로 제거해 train 7,566, dev 1,079, test 2,194문항을 고정했다. 시험 ID와 순서는 보존하며 시험 입력에는 정답과 사람 설명을 제공하지 않는다. [전처리 명세](../../artifacts/ecqa/data_manifest.json), [기존 SFT 조건](../v1/RESEARCH_PLAN.md).

| 역할 | 고정 모델·초기값 |
|---|---|
| 직접 경로 교사·중간 교사 학습의 교사 | Qwen3.5 4B SFT 선정 E2 동결본 |
| 2B KD 초기값 | 공통 2B SFT 선정 E2의 독립 사본 |
| 0.8B KD 초기값 | 공통 0.8B SFT 선정 E3의 독립 사본 |
| 최종 기준선 | 고정 0.8B SFT 시험 결과 한 개 |

SFT는 재학습하지 않는다. 세 시드는 KD의 반복이며 독립 SFT 초기화 세 개를 뜻하지 않는다. 같은 기준선 결과를 세 번의 SFT 반복으로 세거나 SFT 시드 SD가 0이라고 해석하지 않는다.

## 3 증류 경로와 학습 조건

| 최종 조건 | 경로 | 중간 교사 |
|---|---|---|
| 직접 FKL | 4B SFT → 0.8B SFT 사본, FKL | 없음 |
| 직접 RKL | 4B SFT → 0.8B SFT 사본, RKL | 없음 |
| 중간 FKL | 4B → 2B → 0.8B, FKL → FKL | 같은 시드 TA-FKL E3 |
| 중간 RKL | 4B → 2B → 0.8B, RKL → RKL | 같은 시드 TA-RKL E3 |

각 시드의 실행 순서는 ta_fkl→ta_rkl→direct_fkl→direct_rkl→via_fkl→via_rkl이다. 최종 0.8B 학생은 각 조건에서 동일한 SFT 초기값의 독립 사본으로 시작하고 단계마다 새 optimizer·scheduler를 사용한다.

교사와 학생의 확률을 각각 p(v), q(v)라 하면 FKL은 Σ p(v) log[p(v)/q(v)], RKL은 Σ q(v) log[q(v)/p(v)]이다. 동일한 질문·선택지·사람 정답·설명 접두열에서 전체 어휘 248,320개의 순수 KL을 응답·EOS 위치에 대해 평균한다. RKL의 q 가중치도 미분하며 prompt·padding 위치는 제외한다.

| 항목 | 고정 조건 |
|---|---|
| 학습 예산 | KD 단계마다 3에포크·1,419 updates, 에포크당 473 updates |
| 시드 | seed=data_seed=10·20·30 |
| 목적함수 | T=1·순수 KL, CE 혼합 없음, 같은 참조 prefix |
| LoRA | r=8·α=32·dropout=0·all-linear |
| 학습률·배치 | 5×10⁻⁶, microbatch 1×누적 16 |
| 최적화 | AdamW β .9/.999·ε 10⁻⁸·weight decay 0·gradient clip 1 |
| 스케줄 | 단계별 새 linear scheduler, warmup 71 updates |
| 정밀도 | BF16 base·FP32 trainable LoRA·FP32 KL |
| 계산 | 응답 토큰 16개 단위 재계산, 전체 어휘·응답 유지, 양자화·CPU offload 없음 |
| 자원 보호 | 여유 VRAM 2GiB·가용 RAM 4GiB·문항 60초 |

중간 경로의 최종 0.8B 학생도 KD는 한 번 수행한다. 다만 경로 전체에는 별도의 2B KD가 추가되므로 같은 총 FLOPs나 총 시간으로 비교한 실험은 아니다.

## 4 모델 선정과 평가

증류 단계별 공통 예산을 완주한 E3를 주 시험 가중치로 사용한다. 검증 자료는 E1·E2·E3의 추이를 확인하는 데 활용하며 시험 점수로 에포크를 교체하지 않는다. E1·E2는 3에포크 스케줄의 중간 저장본이며 독립적인 1·2에포크 완결 학습이 아니다. E3 고정은 최적 시점이나 수렴의 증거가 아니다.

시험은 같은 2,194문항에서 non-thinking·greedy·batch 1·ANSWER→EXPLANATION 형식·최대 새 출력 256토큰으로 수행한다. 처음 생성한 ANSWER를 재파싱해 ACC·Macro-F1을 계산한다. ANSWER 위치 A–E 조건부 확률의 정답 NLL과 Brier를 주 지표로 사용한다. NLL은 자연로그를, Brier는 다섯 선택지의 제곱오차 합을 문항 평균한다. 전체 설명 시퀀스 NLL이나 설명 사실성 점수가 아니다.

상한은 EOS 없이 새 출력 256토큰에 도달한 문항 수다. 상한에 도달해도 유효한 첫 답은 채점하며 문항 제외·재호출·상한 확대를 하지 않는다.

## 5 분석 규칙

1. 각 시드의 네 학생과 세 시드 평균·표본 SD(ddof=1)를 보고한다.
2. ΔF=중간 FKL−직접 FKL, ΔR=중간 RKL−직접 RKL과 ΔR−ΔF를 지표별로 계산한다. ACC 차이는 %p다.
3. 같은 문항 ID를 모든 모델과 시드에 공통 적용해 20,000회 복원 부트스트랩한다. 통계 시드는 20261027, 구간은 백분위 개별 95%다. Macro-F1과 차이·차이의 차이도 매 재표집에서 계산한다.
4. ACC는 같은 문항의 정오 불일치에 대한 양측 정확 McNemar 검정을 적용한다. 시드별 8개 비교는 SFT 대비 네 학생, 같은 KL의 직접–중간 두 쌍, 같은 경로의 FKL–RKL 두 쌍이다. 각 시드에서 Holm 보정하고 원 p값과 보정 p값을 함께 보고한다.
5. 교사 오답에서 학생의 같은 오답·정답 교정 건수를 집계하되 관측 중첩을 인과적 오류 전달로 부르지 않는다.
6. 학습·dev, 시험 생성, 이전 중단 세션, 로딩·probe·검증·대기를 구분해 비용 범위를 설명한다.

세 시드의 2,194문항을 독립된 6,582문항으로 합쳐 검정하지 않는다. 문항 구간은 고정된 세 학습 결과에 조건부이며 학습 시드 모집단의 구간이나 동시 신뢰구간이 아니다. 유의하지 않은 차이를 동등성 입증으로 해석하지 않는다.

## 6 기존 결과 활용과 검증

동일 조건인 시드 10의 완료 가중치와 응답은 원래 시각·SHA·지표를 보존해 활용했다. 시드 10 학습 5단계와 시험 3회가 이에 해당한다. 교사가 TA-FKL E2에서 E3로 바뀐 시드 10 중간 FKL은 고정 SFT 초기값에서 새로 학습했다. 논리적 실험은 18개 KD 단계·18개 전체 시험이며 실제 추가 학습은 13단계, 추가 전체 시험은 15회다. 기존 응답을 새 생성으로 표시하지 않는다.

완료 검증은 원문 첫 ANSWER·동일 ID/gold·평가 조건·adapter SHA·모든 지표·원문 manifest SHA를 CPU에서 대조했다. 공개 집계에는 문항 원문과 응답 대신 검증 해시와 집계만 포함한다.

## 8 주장 범위

단일 SFT 초기값에서의 세 KD 시드, 한 데이터셋·모델 계열, 고정 LR·온도·LoRA 조건에 한정한다. 중간 경로의 추가 2B 학습과 교사 크기·분포의 영향을 분리한 순수 경로 인과 효과를 주장하지 않는다. NLL·Brier의 변화를 내부 표현·확률 보정만의 개선이나 설명 사실성의 개선으로 확대하지 않는다.
