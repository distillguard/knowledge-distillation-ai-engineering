## 결과의 핵심

동일 test 2,194문항에서 직접 RKL의 ACC·Macro-F1이 가장 높았고, 중간 FKL의 NLL·Brier가 가장 낮았다. 중간 경로의 ACC는 대응 직접 경로보다 FKL 1문항, RKL 9문항 낮았다. 중간 경로가 모든 지표에서 나빴다는 결과는 아니다.

ΔF=ACC(중간 FKL)−ACC(직접 FKL), ΔR=ACC(중간 RKL)−ACC(직접 RKL)로 정의하면 각각 −0.045579%p, −0.410210%p이고 ΔR−ΔF는 −0.364631%p다. 단일 시드·모델 계열·데이터셋의 서술적 차이이며 통계적 유의성이나 인과적 원인을 검증한 값은 아니다.

## 공개 범위와 원고 상태

이번 갱신은 위 Markdown 문서만 포함한다. HWP·PDF·미리보기 이미지, 응답 원문, 가중치·체크포인트, 로그, 로컬 실험 집계와 현재 ECQA 실행 코드는 이 커밋에 포함하지 않는다. 문서에 적은 로컬 근거 경로는 기록의 위치이며 공개 다운로드 링크가 아니다.

공식 양식을 적용한 2페이지 HWP와 PDF는 로컬에 보관했다. 저자명·소속·이메일·지도교수는 입력이 필요하며 학회에 제출하지 않았다. 저장소에 남아 있는 이전 GPT-2/Dolly 연구 파일은 과거 기록이며, 현재 ECQA 연구를 재현하는 실행 코드로 안내하지 않는다.
